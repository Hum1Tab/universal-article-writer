# Logic Report（見本）

## 1. 結論

在宅勤務は知識労働者の主観的生産性を高める可能性がある。

## 2. 前提

- P1 [TEXT]: 無作為化比較試験で、週2日群の自己申告生産性が対照群より4.2%高かった。
- P2 [CONV]: 自己申告生産性は、実際の生産性の代理指標としてある程度使える。
- 隠れた前提 [ANALYST]: 3か月の試験結果が、長期の効果を代表する。

## 3. 推論の型

帰納（単一のRCTからの一般化）。因果主張には識別仮定が要る。

## 4. 反例・代替説明

選択効果、逆因果、自己申告バイアス。無作為化は選択効果を弱めるが、長期のキャリア形成は測れていない。

## 5. 反証条件

C01: 同じ集団・同じ指標で効果が再現しない、または自己申告と客観指標が乖離する場合、主観的生産性の主張を撤回する。

## 6. 未解決

長期のイノベーションへの影響、職種による異質性の大きさ。

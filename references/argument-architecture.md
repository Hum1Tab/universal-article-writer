# Argument Architecture

Phase 3 の詳細。目的は「それらしい意見」を並べることではなく、**反論可能な結論を、検証可能な根拠と明示的な推論で支える**こと。

---

## 1. 問いの型を決める

問いの型を間違えると、証拠の種類も結論の形もずれる。まず問いを次のどれかに分類する。

| 型 | 問いの例 | 結論の形 | 必要な論証 | 典型的な失敗 |
|---|---|---|---|---|
| 記述 `descriptive` | 何が、どれくらい、どこで起きているか | 「X は Y である（範囲・時点付き）」 | 代表的なデータ、定義、測定 | 一事例を全体に一般化 |
| 因果 `causal` | X は Y を変えるか | 「X は Y を増やす／減らす。ただし Z の条件下で」 | 反事実、交絡統制、時間順序、メカニズム | 相関を因果とする |
| 予測 `predictive` | 将来どうなるか、未知のケースを当てられるか | 「条件 C のもとで、X が起きる確率は P」 | 外部検証、キャリブレーション、ベースレート | 訓練データの成績を通用力と混同 |
| 評価 `evaluative` | X は良い／悪い／望ましいか | 「基準 B に照らして、X は Y と評価できる」 | 事実＋評価基準＋価値前提＋分布効果 | 事実から規範を直接導く |
| 解釈 `interpretive` | このテキスト／出来事は何を意味するか | 「X は Y と読める。なぜなら Z だから」 | 文脈、テキスト上の根拠、代替解釈 | 自分の読みを唯一の意味とする |
| 概念 `conceptual` | 概念の定義・関係は妥当か | 「X は Y と区別すべきである。定義は Z」 | 定義、区別、反例、論理的一貫性 | 定義のすり替え、循環論法 |
| 政策 `policy` | 何をすべきか | 「目的 P には手段 M が有望。条件 C で」 | 効果、実装可能性、副作用、代替案、分布 | 効果だけを見て実装を無視 |

**ルール**：1つの記事で複数の型を扱うのはよい。ただし、**節ごとにどの型の主張をしているかを意識する**。因果の節に記述的証拠しかないなら、結論を因果から記述に弱める。

## 2. 結論（thesis）の作り方

### 2.1 良い結論の条件

1. **1文で言える。**
2. **反論可能である。** 反対する人が、どの証拠を出せば崩せるか想像できる。
3. **範囲が限定されている。** 対象、期間、条件、程度のいずれかが特定されている。
4. **問いに答えている。** 問いをずらしていない。
5. **証拠の強さと一致している。** 観察研究なら「示唆する」、RCT なら「示す」。
6. **結論のなかに、結論を支える条件が入っている。**

### 2.2 使える型

- **条件付き因果**：「知識労働者への週2日の在宅勤務は、通勤時間の削減を通じて、短期的には主観的生産性を高める。ただし、協働が密接な職種では効果が小さい可能性がある。」
- **範囲限定の記述**：「日本の2020〜2023年のデータでは、X の増加は主に60歳以上で起きていた。」
- **証拠の不在**：「現時点の質の高い研究は、X が Y を改善するという主張を支持しない。ただし、Z の集団では未検証である。」
- **規範の条件付き**：「効率性のみを基準にすれば M が優れる。しかし分配の公平性を含めると、M には補償措置が必要である。」
- **探索的**：「現時点で言えるのは、X は Y と相関するが、因果の方向とメカニズムは未確定だ、ということである。」

### 2.3 悪い結論のパターン

| パターン | 例 | 何が悪いか | 修正 |
|---|---|---|---|
| 広すぎる | 「AI は教育を変える」 | 反証不能、範囲不明 | 誰の、どの教育を、どう変えるのか |
| 同語反復 | 「良い政策は成果を出す」 | 情報量ゼロ | 政策の具体名と成果指標を入れる |
| 二つの結論 | 「X は有効だが、無効でもある」 | 矛盾を隠している | 条件を分けて整理する |
| 問いをずらす | 「遠隔勤務は生産性を上げるか」→「働き方改革が必要だ」 | 問いに答えていない | 問いに戻る |
| 証拠より強い | 横断研究から「X が Y を引き起こす」 | 因果の飛躍 | 「関連する」に弱める |
| 価値判断の混入 | 「X は不公平だ。データが示すように」 | 事実と規範の混同 | 評価基準を明示する |

### 2.4 反証可能性テスト

結論を書いたら、自問する。

> **この結論に反対する合理的な人は、どんな観察を突きつければよいか？**

- 答えられない → 結論が曖昧すぎるか、反証不能である。
- 「そんな観察は存在しない」→ 強い結論だが、証拠の強さが足りているか確認する。
- 複数の観察が出てくる → それが荷重主張の反証条件になる。

## 3. Toulmin モデル

論証を6つの要素に分解する。記事の本文には全部を書かない。**書かない要素こそ、監査で確認する。**

| 要素 | 問い | 例（在宅勤務と生産性） |
|---|---|---|
| **Claim** | 何を主張するか | 週2日の在宅勤務は、知識労働者の主観的生産性を高める。 |
| **Grounds** | どんな証拠があるか | [S03] のRCTでは、週2日群の自己申告生産性が4.2%高かった（n=1,200、95%CI 1.1–7.3）。 |
| **Warrant** | その証拠が、なぜ主張を支えるのか | 自己申告生産性が、実際の成果と一定の相関を持つなら、主観的指標でも傾向は捉えられる。 |
| **Backing** | Warrant を支える理論・定義・前提 | 複数の研究で、自己申告と客観的成果の相関は r=0.4〜0.6 と報告されている [S07]。 |
| **Qualifier** | どの範囲で、どの程度か | 知識労働者、週2日、3ヶ月以内、協働密度が中程度以下の職種。 |
| **Rebuttal** | 反論と、それへの応答 | 選択効果（在宅勤務を選ぶ人だけが生産性が高い）→ RCT なので無作為化で対処。ただし、長期のキャリア効果は不明。 |

### 3.1 よくある Toulmin の失敗

1. **Warrant の省略** — 証拠と主張の間に飛躍がある。読者は「なぜ？」と思う。
2. **Backing が権威だけ** — 「著名な研究者が言っているから」は Warrant の支持にならない。
3. **Qualifier の欠落** — すべての集団・期間に通用するかのように読める。
4. **Rebuttal が藁人形** — 反対側の最強の主張を避けている。
5. **Grounds が結論の言い換え** — 証拠ではなく、主張の繰り返しになっている。
6. **Warrant が複数** — 1つの論証に暗黙の前提が何層もあり、どれが崩れたら結論が崩れるか不明。

### 3.2 Warrant の監査質問

各荷重主張について、次を紙に書く。

- この証拠からこの主張が出るには、どんな一般原則が必要か。
- その原則は、本文で明示されているか。それとも読者の常識に依存しているか。
- その原則は、この分野で受け入れられているか。異論はあるか。
- その原則が成り立たない範囲はどこか。
- 反例はあるか。

**Warrant を1文で書けないなら、その論証はまだ完成していない。**

## 4. 推論の形式と監査

### 4.1 演繹

前提が真なら結論が必ず真になる推論。

- **妥当性（validity）**：形式が正しいか。
- **健全性（soundness）**：前提も真か。
- **隠れた前提**：書かれていない前提はないか。

例：
> すべての A は B である。X は A である。ゆえに X は B である。

監査：A の定義は一貫しているか。X は本当に A か。「すべて」は本当にすべてか。

### 4.2 帰納

観察の集合から一般化する推論。

- サンプルは母集団を代表しているか。
- サンプルサイズは足りるか。
- 反例はないか。
- 観察された範囲を超えて一般化していないか。
- 選択バイアス、生存者バイアスはないか。

**「N 件の事例で X だった」は、「すべての X である」の証明ではない。**

### 4.3 アブダクション（最良の説明への推論）

観察を最もよく説明する仮説を選ぶ推論。因果メカニズムの議論でよく使う。

評価基準：
1. **説明範囲** — どれだけの観察を説明できるか。
2. **簡潔さ** — 余計な仮定が少ないか。
3. **メカニズム** — 実際にどう働くか説明できるか。
4. **予測的成功** — 新しい予測が当たるか。
5. **背景知識との整合** — 既存の理論と矛盾しないか。
6. **反証可能性** — どんな観察で崩れるか。

**警告**：説得力のある物語は、証拠の代わりにならない（narrative fallacy）。「もっともらしい」と「正しい」は違う。

### 4.4 アナロジー

既知の事例から未知の事例を推論する。

- **対応関係**：何と何を対応させているか。
- **非類似点**：重要な違いは何か。
- **目的**：説明のためか、予測のためか、説得のためか。
- **限界**：どこまでなら妥当か。

監査質問：「このアナロジーは、どこまで同じで、どこから違うか。違う部分は結論に影響するか。」

### 4.5 因果推論

因果主張には、次のいずれかの識別戦略が必要である。

- 無作為化（RCT）
- 自然実験（DiD、IV、RDD、イベントスタディ）
- 傾向スコア、マッチング、回帰調整（観察された交絡のみ）
- 操作変数、媒介分析
- メカニズム証拠、時間順序、用量反応、頑健性

監査質問：
- 反事実は何か。比較対象は適切か。
- 交絡はすべて測れたか。未測定の交絡はどれくらいありそうか。
- 逆因果の可能性はあるか。
- 同時期の他の変化（secular trend）はないか。
- 効果の大きさは、メカニズムから見て妥当か。
- 外挿できる範囲はどこまでか。

### 4.6 統計的推論

- 効果量と信頼区間を見る。p値だけを見ない。
- 「統計的に有意」は「実質的に重要」ではない。
- 「非有意」は「効果なし」ではない。信頼区間が重要効果を排除しているか確認する。
- ベースレートを無視しない。
- 多重比較を補正しているか。
- サブグループは事前指定か、後付けか。
- 欠測はランダムか。
- 分母は何か。誰が除外されたか。

### 4.7 規範的推論

「〜である」から「〜べきである」は直接出ない（is-ought gap）。規範的主張には、明示的な価値前提が必要である。

- **帰結主義**：幸福、効用、コスト、便益。
- **義務論**：権利、義務、尊厳、手続きの公正。
- **徳倫理**：性格、関係、善い生。
- **正義論**：分配、機会、格差、誰が負担するか。
- **政治哲学**：自由、平等、正当性、公共的理由。

政策主張なら、次も必要である。

- 目的は何か。誰のための目的か。
- 手段は目的を達成するか。効果の大きさは十分か。
- 実装可能か。コスト、法制度、行政能力は。
- 副作用は何か。誰が傷つくか。
- 代替案は何か。何もしない場合と比べてどうか。
- 分配効果はどうか。平均値の裏で誰が取り残されるか。

### 4.8 解釈

テキスト・出来事・文化現象の意味を読む。

- 文脈（歴史、制度、著者の位置、読者）。
- テキスト上の根拠（語彙、比喩、構成、沈黙）。
- 代替解釈。なぜ自分の読みがより良いか。
- 解釈の妥当性は、完全には反証できない。しかし、**テキストに反する読み**は棄却できる。
- 著者の意図と、テキストの効果を混同しない。

## 5. 反論の設計

### 5.1 反論の3層

| 層 | 反論の内容 | 例 | 応答の仕方 |
|---|---|---|---|
| **証拠への反論** | データが間違っている、偏っている、別の研究がある | 「その RCT は短期間で、長期効果は不明だ」 | 証拠の限界を認め、結論を限定する |
| **推論への反論** | Warrant が成り立たない、交絡がある、別の説明が可能 | 「自己申告生産性は、在宅勤務への好みを反映しているだけだ」 | 代替説明を検討し、識別戦略を示す |
| **フレームへの反論** | 問いの前提、評価基準、単位が間違っている | 「生産性を上げることが目的なのか。労働者の福祉は？」 | 前提を明示し、必要なら問いを再設定する |

### 5.2 Steelman プロトコル

最強の反論を書くときは、次の手順を踏む。

1. **相手の立場を、相手の言葉で書く。** 自分の都合の良い要約をしない。
2. **相手の最良の証拠を探す。** 反対側の主要な研究を1つ以上読む。
3. **相手が認める条件を探す。** どこでなら自分と一致するか。
4. **自分の結論が崩れる条件を書く。** 反論が正しければ、どこを変えるか。
5. **相手に読ませる。** 「それで合っているか」と聞ける形になっているか。

**テスト**：反対立場の専門家が読んで「よく理解している」と言うか。言わなければ、まだ strawman である。

### 5.3 代替説明のチェックリスト

因果主張を見たら、次の代替説明を検討する。

- **交絡**：第三の変数が両方に影響していないか。
- **逆因果**：Y が X を引き起こしていないか。
- **選択効果**：X を受ける人と受けない人が、もともと違わないか。
- **測定誤差**：X や Y の測定が、結果を歪めていないか。
- **偶然**：サンプルサイズ、多重比較、p-hacking。
- **出版バイアス**：有意な結果だけが出版されていないか。
- **時間トレンド**：同時期の別の変化が影響していないか。
- **回帰平均**：極端な値が平均に戻っただけではないか。
- **生存者バイアス**：脱落した人・失敗した事例が見えていないか。
- **Hawthorne 効果**：観察されていること自体が行動を変えていないか。
- **需要特性**：参加者が期待に沿って答えていないか。

### 5.4 応答の型

| 応答 | いつ使うか | 書き方 |
|---|---|---|
| **譲歩** | 反論が正しい、または自分が言い過ぎた | 「この点は認める。したがって結論を X に限定する。」 |
| **限定** | 反論は一部の範囲で正しい | 「Z の集団では正しい。しかし W では当てはまらない。」 |
| **反駁** | 反論の事実認識・推論が誤っている | 「その研究は Y を測っていない。したがって X への反証にはならない。」 |
| **再枠組み** | 反論は正しいが、問いのレベルが違う | 「効果の大きさは小さい。しかし制度設計上は無視できない。」 |
| **保留** | 現時点で決められない | 「この点は未解決である。結論は条件付きにとどめる。」 |

**禁止**：反論を無視する、弱い版本だけを扱う、論点をすり替える、相手の人格を攻撃する、両論併記で逃げる。

## 6. フレーム批判

問い自体が間違っている可能性を、1回は真剣に検討する。これを怠ると、どれだけ内部的に整合していても、**間違った問いに対する良い答え**になる。

### 6.1 前提の棚卸し

問いを分解し、暗黙の前提を列挙する。

例：「日本は移民を受け入れるべきか」
- 前提1：移民を受け入れるかどうかは、国家政策として選択できる。
- 前提2：移民には経済効果がある（または文化的影響がある）。
- 前提3：現在の人口動態が問題である。
- 前提4：国民国家の枠組みが所与である。
- 前提5：「受け入れる／受け入れない」の二択である。

各前提について問う：「これは本当に所与か。別の見方はないか。」

### 6.2 フレームのチェックリスト

- **二分法**：A か B かではなく、C はないか。何もしない（status quo）は含まれているか。
- **問いの誘導**：「なぜ X は悪いのか」は、X が悪いことを前提にしている。
- **単位**：個人、世帯、企業、自治体、国家、世界のどれで見るか。単位を変えると結論が変わるか。
- **時間軸**：短期と長期で結論が変わるか。
- **分布**：平均だけでなく、中央値、分散、最弱層への影響を見ているか。
- **見えていない声**：誰がこの問いから排除されているか。未来世代、非人間、少数派、現場の労働者。
- **分野の前提**：経済学の合理性、心理学の個人主義、法学の権利概念など、分野固有の前提を無批判に使っていないか。
- **逆の問い**：逆方向の問いを立てたら、どんな結論になるか。
- **代替の問い**：問いを立て直すと、より重要な問題が見えるか。

### 6.3 フレームの帰結

検討した結果、次のいずれかを選ぶ。

1. **維持**：前提は妥当。本文で明示する。
2. **再設定**：問いを変える。変更理由を書く。
3. **二重フレーム**：両方の問いを併記し、それぞれに答える。
4. **拒否**：問い自体が有害・不毛。別の問いを提案する。

**「問いが間違っている」と言うだけでは不十分**。代替の問いと、それに答えるための証拠を示す。

## 7. 構成

構成はテンプレートに合わせない。**論証の形が構成を決める。**

| パターン | 使うとき | 節の仕事 | 注意 |
|---|---|---|---|
| **Thesis-first** | 政策提言、オピニオン、明確な結論がある | 結論→理由→反論→含意 | 序盤で結論を出した後、都合の良い証拠だけを並べない |
| **Problem → Diagnosis → Remedy** | 実務、政策、組織課題 | 問題の定義→原因→処方 | 原因を飛ばして処方に走らない |
| **Position → Objection → Synthesis** | 論争、批評、学術エッセイ | 自分の立場→最強の反論→統合 | 反論を弱くしない。統合が本当に統合になっているか |
| **Phenomenon → Mechanisms → Implications** | 解説、科学記事 | 現象→メカニズム→意味 | メカニズムの証拠が弱いのに断定しない |
| **Question → Landscape → Themes → Debate → Gap** | 文献レビュー | 問い→全体像→テーマ→論争→空白 | 論文の要約を並べない。テーマで統合する |
| **IMRaD** | 実証論文 | 背景→方法→結果→考察 | 分野の慣例に従う。方法の詳細を省略しない |
| **Chronological** | 歴史、事例、プロセス | 時系列→転換点→意味 | 年表の羅列にしない。因果と解釈を入れる |
| **Compare / Contrast** | 比較、選択肢の検討 | 基準→比較→評価 | 比較基準を先に明示する。偽の均衡に注意 |
| **Definitional** | 概念論文、用語の整理 | 定義→区別→反例→含意 | 定義のすり替え、循環論法に注意 |
| **Policy brief** | 意思決定者向け | 提言→根拠→実装→リスク | 効果の大きさ、コスト、分配、法的制約を入れる |

### 7.1 節の仕事を1文で書く

各節に「この節の仕事」を1文で書く。仕事のない節は削る。

例：
- 序論：「読者に問いを渡し、なぜ今それが重要かを示す。」
- 背景：「読者が本文を理解するために必要な最小限の概念を定義する。」
- 証拠節：「X と Y の関連を、独立した3つのデータで示す。」
- 反論節：「最も強い反対結論を提示し、その限界を示す。」
- 結論：「問いに答え、条件と未解決点を明示する。」

**「背景」「先行研究」「考察」といった見出しは、仕事を書いていないことが多い。** 見出しを読んだだけで節の主張がわかるようにする。

### 7.2 アウトラインの型

```
## 問い
- 問い：
- 読者：
- 結論（仮）：

## 節1：
- 仕事：
- 荷重主張：
- 証拠：
- 扱う反論：
- 読み終えた読者の状態：

## 節2：
...
```

## 8. 荷重主張と反証条件

### 8.1 荷重主張を絞る

荷重主張（load-bearing claim）は、それが崩れたら結論が崩れる主張である。3〜5個に絞る。

- 多すぎる → どれが重要かわからない。読者が疲れる。
- 少なすぎる → 結論が単一の証拠に依存する。脆弱。
- それぞれに、独立した証拠と Warrant が必要。
- 荷重主張同士の依存関係を書く（A が崩れたら B も崩れる、など）。

### 8.2 反証条件を書く

各荷重主張に「何が観察されたら撤回するか」を書く。

例：
> 主張：週2日の在宅勤務は生産性を高める。
> 反証条件：同一職種・同一期間の RCT で、在宅勤務群の客観的成果が対照群より低い、または差が信頼区間含めてゼロに近い。

**反証条件が書けない主張は、記事から削るか、探索的記述に弱める。**

### 8.3 プレモーテム

記事を公開した1年後、最も批判されるとしたらどこか。次を検討する。

- 最も弱い証拠に依存している主張はどれか。
- 最も強い反論を、自分は本当に理解しているか。
- 最も起きそうな誤解は何か。
- データの更新で結論が変わる可能性はないか。
- 想定していない聴衆（現場、少数派、反対派）はどう読むか。

## 9. 論証の誤謬

### 9.1 形式誤謬

| 誤謬 | 形 | 例 | 見分け方 |
|---|---|---|---|
| 後件肯定 | P→Q, Q, ∴P | 「規制すれば安全になる。安全になった。ゆえに規制が原因だ」 | 他の原因を排除していない |
| 前件否定 | P→Q, ¬P, ∴¬Q | 「規制しなければ安全でない。規制した。ゆえに安全だ」 | 条件の逆は成り立たない |
| 中項不周延 | すべての A は B、すべての C は B、∴すべての A は C | 「医者は忙しい。彼は忙しい。ゆえに彼は医者だ」 | 共通項が全体をカバーしていない |
| equivocation | 同じ語を異なる意味で使う | 「自由」を経済的自由と政治的自由で混用 | 定義の一貫性 |

### 9.2 非形式的誤謬

| 誤謬 | 記事での現れ | 修正 |
|---|---|---|
| 権威への訴え | 「ノーベル賞学者が言うように」 | 主張と証拠を直接示す |
| 人格攻撃 | 「著者は業界の人間だから」 | 利害関係は開示するが、主張の真偽は別 |
| 偽の二分法 | 「規制か自由か」 | 第三の選択肢を探す |
| 滑り坂 | 「一度許せば、すべて崩れる」 | 各段階の確率とメカニズムを示す |
| 藁人形 | 相手の主張を極端に要約 | steelman を書く |
| 論点ずらし | 別の争点にすり替える | 元の問いに戻る |
| お前も同じ | 「相手も不正をしている」 | 行為の正当化にはならない |
| チェリーピッキング | 都合の良い研究だけ引用 | 反対証拠を探す |
| 生存者バイアス | 成功した企業だけ分析 | 失敗した事例を探す |
| ベースレート無視 | 「検査で陽性だから99%病気」 | 事前確率を入れる |
| 結合錯誤 | 「A かつ B の方が A より確からしい」 | 確率の大小を確認 |
| 回帰平均 | 「最悪の年から改善した。政策の効果だ」 | 平均への回帰を考慮 |
| 生態学的誤謬 | 国の平均から個人を推測 | 単位を揃える |
| 合成・分割 | 全体の性質を部分に、部分を全体に | 単位を確認 |
| 事後因果 | 「X の後で Y が起きた。X が原因だ」 | 時間順序だけでは因果にならない |
| 自然への訴え | 「自然だから良い」 | 規範は別に正当化する |
| is-ought | 事実から規範を導く | 価値前提を明示 |
| モット・アンド・ベイリー | 強い主張と弱い主張を行き来 | 主張を固定する |
| ゴールポスト移動 | 反証されたら基準を変える | 事前に反証条件を決める |
| 偽の均衡 | 証拠が偏っているのに両論併記 | 証拠の重みを示す |
| 物語の誤謬 | もっともらしい筋書きで因果を証明 | メカニズムと反証を確認 |

### 9.3 統計・因果の誤謬

- **相関→因果**：交絡、逆因果、選択。
- **非有意→効果なし**：信頼区間を見る。
- **有意→重要**：効果量を見る。
- **相対リスクの誇張**：絶対リスクと並べる。
- **分母の無視**：「倍になった」の元の数は。
- **サバイバーシップ**：脱落者を無視。
- **Simpson のパラドックス**：全体と層別で逆転。
- **p-hacking**：多重比較、解析の自由度。
- **外挿**：サンプルと母集団の違い。
- **代理指標の誤用**：測定したいものと測っているものの乖離。

## 10. 論証マップの書き方

`assets/argument-map.md` を使い、少なくとも次を埋める。

| 項目 | 内容 |
|---|---|
| `claim_id` | `C01` 形式 |
| `claim` | 1文の主張 |
| `type` | descriptive / causal / predictive / mechanistic / evaluative / interpretive / conceptual / policy |
| `grounds` | 証拠IDと箇所 |
| `warrant` | 証拠が主張を支える理由 |
| `backing` | Warrant を支える理論・定義・前提 |
| `qualifier` | 範囲・程度・条件 |
| `rebuttal` | 最強の反論 |
| `response` | 応答（譲歩・限定・反駁・再枠組み・保留） |
| `confidence` | high / medium / low |
| `falsifier` | 撤回条件 |
| `depends_on` | 依存する他の主張 |
| `status` | supported / partially-supported / contested / unverified |

**ルール**：`grounds` が空の荷重主張は、記事に書かない。`warrant` が空の主張は、証拠の羅列になる。`falsifier` が空の主張は、信仰に近い。

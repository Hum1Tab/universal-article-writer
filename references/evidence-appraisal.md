# Evidence Appraisal

Phase 2 の詳細。目的は「論文を信じる／疑う」の二択ではなく、**この証拠から、どこまで言えるのか**を決めること。

---

## 1. まず主張の種類を決める

| 主張タイプ | 問いの形 | 必要な証拠 | よくある誤り |
|---|---|---|---|
| 記述的 `descriptive` | 何が、どれくらい、どこで起きているか | 代表的なサンプル、定義、測定、時点 | 一部の事例を全体に一般化 |
| 因果 `causal` | X は Y を変えるか | 反事実、無作為化または自然実験、交絡統制、頑健性 | 相関を因果とする、逆因果、交絡 |
| 予測 `predictive` | 将来・未知のケースを当てられるか | 外部検証、キャリブレーション、判別、ベースレート | 訓練データの精度を通用力と混同 |
| メカニズム `mechanistic` | なぜ X が Y を生むのか | 構成要素、介入、時間順序、必要/十分条件 | 物語の説得力で因果を証明した気になる |
| 評価 `evaluative` | X は良い/悪い/望ましいか | 事実＋評価基準＋価値判断＋分布効果 | 事実から規範を直接導く |
| 解釈 `interpretive` | このテキスト/出来事は何を意味するか | 文脈、テキスト、代替解釈、内部的整合性 | 自分の読みを唯一の意味とする |
| 概念的 `conceptual` | 概念の定義・関係は妥当か | 定義、区別、反例、論理的一貫性 | 定義のすり替え、循環論法 |

**ルール**：主張タイプと証拠タイプを一致させる。観察研究の相関は因果主張の根拠にならない。予測モデルの精度はメカニズムの証明ではない。事実の記述は価値判断の代わりにならない。

---

## 2. 研究デザインの早見表

| デザイン | 強み | 弱み | 因果推論 |
|---|---|---|---|
| RCT | 無作為化で交絡を制御 | 外部妥当性、倫理、コスト、遵守 | 強い（ただしプロトコル次第） |
| 自然実験（DiD, IV, RDD） | 現実の政策を利用 | 仮定が強い、逃げ道が多い | 中〜強（仮定の検証が必須） |
| コホート | 時間順序、稀な曝露 | 交絡、脱落、測定 | 中 |
| ケースコントロール | 稀な結果 | 選択バイアス、想起バイアス | 弱〜中 |
| 横断研究 | 安価、探索的 | 時間順序不明、交絡 | 弱（相関のみ） |
| 時系列 | 傾向、政策前後 | 同時期の他の変化、季節性 | 中（対策次第） |
| 質的研究 | 意味、プロセス、文脈 | 一般化、再現性、分析者の影響 | 因果ではなく理解 |
| シミュレーション | 反事実、感度分析 | モデルの仮定に依存 | 仮定次第 |
| 事例研究 | メカニズム、例外的現象 | 選択、一般化 | 仮説生成向き |

**GRADE の考え方**（観察研究の証拠を格下げする理由）：リスクオブバイアス、非一貫性、非直接性、不精確さ、出版バイアス。RCT でもこれらの理由で下げる。デザインのラベルだけで格付けしない。

## 3. バイアスと交絡のチェック

### 選択・サンプリング

- 誰が研究に入り、誰が入らなかったか。
- 生存者バイアス、募集バイアス、自己選択。
- 追跡不能・脱落（attrition）。脱落が結果と関連しているか。
- 健康労働者効果、参加者効果（研究やプログラムに参加する人だけが対象になる）。

### 測定

- アウトカムは妥当な指標か。代理指標（surrogate）ではないか。
- 測定者・回答者のバイアス（ blinding の有無）。
- 想起バイアス、社会的望ましさ、天井/床効果。
- 測定の信頼性・再現性。単位・機器・時期の一貫性。

### 交絡

- 結果と曝露の両方に影響する第三の変数。
- 時間依存の交絡、同時期の政策変更。
- 観察された交絡を調整しても、未測定の交絡は残る。
- 「調整したから因果」ではない。どの変数を、なぜ調整したかを確認する。
- 不適切な調整：中間変数（mediator）の調整、collider の調整。

### 分析・報告

- 主要アウトカムの事前指定。サブグループの後付け。
- 多重比較。p値のハッキング。
- 解析の自由度（研究者自由度）。
- 出版バイアス、ファイルドロワー。
- 都合の良い結果だけを報告していないか。
- 効果量と信頼区間。p値だけを見ない。

### 認知・argument のバイアス

- 確証バイアス：支持する証拠だけを集める。
- 利用可能性：印象的な事例を一般化する。
- アンカリング：最初の数字に引きずられる。
- サンクコスト：自分の立場を守るために証拠を解釈する。
- 権威バイアス：著名な研究者・媒体だから正しいとしない。
- 偽の均衡：証拠の強さが違うのに両論併記する。

## 4. 統計の読み方

### p値

- p値は「帰無仮説の下で、このデータ以上に極端な結果が出る確率」。**主張が正しい確率ではない。**
- `p < 0.05` は「効果が大きい」「実務的に重要」を意味しない。
- `p > 0.05` は「効果がない」ことを意味しない。信頼区間を見る。
- 多重比較を補正していない p値は、探索的として扱う。

### 信頼区間

- 効果の不確実性の範囲。点推定だけで語らない。
- 「統計的に有意」でも、区間が実務的に重要でない範囲なら意味が薄い。
- 非劣性・同等性の主張には、事前に定めたマージンと専用の解析が必要。

### 効果量

- 相対リスク、オッズ比、リスク差、標準化平均差、相関係数、NNT。
- 相対効果だけでは、絶対的な影響はわからない。ベースラインリスクが必要。
- オッズ比をリスク比として読まない。
- 標準化平均差は、尺度の意味を忘れやすい。

### 検出力とサンプル

- 小さいサンプルは、効果が大きく見えやすい（勝者バイアス）。
- 事後的な検出力計算は、観察された効果に対する循環になる。設計時の検出力を見る。
- 「有意でない」＝「検出力不足」かもしれない。

### 回帰・モデル

- 線形性、独立性、分布、外れ値、過適合。
- 調整変数の選び方。媒介変数を調整していないか。
- 交互作用を勝手に解釈していないか。
- 時系列の自己相関、季節性、トレンド。
- 機械学習：訓練/検証/テストの分離、交差検証、外部検証、キャリブレーション、データ漏洩。

### よくある誤謬

- 生態学的誤謬：集団の平均を個人に当てはめる。
- シンプソンのパラドックス：全体と層で傾向が逆転する。
- 平均への回帰（regression to the mean）：極端な値の次は平均に戻る。
- 生存者バイアス：生き残ったものだけを見る。
- ベースレート無視：稀な事象の検査陽性を過大評価する。
- 相対リスクの誇張：ベースラインが小さいと、相対効果は大きく見える。
- 代理指標の誤用：測定しやすい指標が、本当に知りたいものを反映しているか。
- 外挿：異なる集団・文脈・用量に、そのまま当てはめる。

## 5. 因果推論

因果主張には、少なくとも以下を書く。

1. **介入/曝露** — 何を、どのくらい、誰に。
2. **比較** — 何と比べるのか（反事実）。
3. **アウトカム** — 何を、いつ、どう測るか。
4. **識別仮定** — 交絡がない、除外制約、単調性、並行トレンドなど。
5. **推定量** — ATE, ATT, LATE, CATE など。
6. **頑健性** — 感度分析、プラセボ、負の対照、代替仕様。

### デザイン別の注意

- **RCT**：無作為化の失敗、遵守率、脱落、盲検化、プロトコル変更、外部妥当性。
- **DiD**：並行トレンド仮定。事前トレンドの検証。同時期の他の政策。
- **IV**：除外制約（操作変数が結果に直接影響しない）。弱い操作変数。
- **RDD**：カットオフ近傍の連続性。操作（manipulation）。帯域幅の選択。
- **マッチング/傾向スコア**：観察された交絡しか調整できない。共通サポート。
- **媒介分析**：媒介変数の測定誤差、交絡、時間順序。

### Bradford Hill の使い方

因果推論の「チェックリスト」ではなく、**視点の集合**として使う。

- 強さ、一貫性、特異性、時間順序、用量反応、生物学的妥当性、整合性、実験、類推。
- どれか1つが欠けても因果を否定できない。全部揃っても証明ではない。
- 特に時間順序と、代替説明の排除を重視する。

### 因果の言い換え

| 言ってはいけない | 言い換え |
|---|---|
| X が Y を引き起こす（観察研究） | X は Y と関連する。因果効果は、〜の仮定の下で示唆される |
| 効果がない | 信頼区間は、実務的に重要な効果を排除していない |
| 予測できるからメカニズムがわかる | 予測精度はメカニズムを特定しない |
| 自然実験だから因果 | 自然実験は仮定に依存する。仮定を検証する |

## 6. 証拠の格付け（実務用）

正式な GRADE を回す余裕がない場合の簡易版。**スコアを平均しない。主張ごとに付ける。**

| レベル | 意味 | 例 |
|---|---|---|
| A | 複数の独立した頑健な研究、または強いデザイン | 複数 RCT のメタ分析、自然実験の再現 |
| B | 1つの強い研究、または複数の観察研究の一致 | 大規模コホート、良好な自然実験 |
| C | 限定的・単一・探索的 | 小規模研究、横断研究、ケースシリーズ |
| D | 逸話・専門家意見・理論のみ | 事例、コメント、モデル |
| ? | 未確認・矛盾・アクセス不能 | 抄録のみ、追試なし、撤回 |

**重要なのはレベルではなく、結論の強さをレベルに合わせること。** C の証拠で「証明された」と書かない。D の証拠で政策を断定しない。

## 7. 矛盾する証拠の扱い

`contradictions.md` に、以下を表で書く。

| 争点 | 主張A（出典） | 主張B（出典） | 違いの理由 | どちらが強いか | 未解決点 |
|---|---|---|---|---|---|

違いの理由としてよくあるもの：

- 集団・国・期間が違う。
- アウトカムの定義が違う。
- 用量・曝露の測り方が違う。
- 交絡の調整が違う。
- 出版バイアス。
- 分析の自由度。
- 本当に効果が文脈依存。

**ルール**：片方を無視しない。両方を提示し、なぜ結論が違うのかを説明する。説明できなければ、結論を「条件付き」にする。

---

## 8. 信頼度のキャリブレーション

各荷重主張に、`high` / `moderate` / `low` / `unverified` を付ける。

- **high** — 強いデザイン、独立した再現、反証に耐えている、メカニズムも整合。
- **moderate** — 複数の証拠があるが、限界・不一致・外挿がある。
- **low** — 単一研究、探索的、サンプル小、交絡の可能性。
- **unverified** — 実物を確認していない、または主張と証拠の対応が不明。

**キャリブレーションの問い**

- この主張が間違っているとしたら、どんな証拠が出るか。
- その証拠を探したか。
- 反対側の専門家は、何を最強の反論とするか。
- 自分の結論は、証拠の強さに比べて強すぎないか。

## 9. 論文1本の評価カード

```
【書誌】S01 / 著者 / 年 / 誌名 / DOI
【問い】何を明らかにしようとしたか
【デザイン】RCT / コホート / 横断 / 質的 / シミュレーション
【対象】誰を、どこで、いつ、何件
【介入/曝露】何を、どのくらい
【比較】何と比べたか
【アウトカム】何を、どう測ったか
【主要結果】効果量、信頼区間、分母、p値
【著者の結論】何と言っているか
【限界】著者が認めた限界 / 認めていない限界
【利害】資金、所属、利益相反
【検証】verified / partial / abstract-only / secondary-only / unverified / retracted
【この記事で使える主張】1文
【言えないこと】1文
【反証条件】何が出たら撤回するか
```

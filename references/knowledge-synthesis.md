# 知識統合エンジン — 多資料読解から文献レビューまで

> 読むタイミング：Phase 1（収集・読解）、Phase 2（証拠評価）、Phase 3（統合・論証）。
> 目的は「たくさん読んだ感」ではなく、**独立した証拠を数え、主張の強さを証拠の強さに合わせ、読者が検証できる形で残す**ことである。

---

## 0. 原則

1. **読んだ資料の数は、証拠の数ではない。** 同じデータを共有する10本の論文は、証拠として1つかもしれない。
2. **要約の束はレビューではない。** テーマで統合し、論争と空白を示す。
3. **一次資料に遡る。** 二次・三次資料は地図であり、根拠ではない。
4. **読めなかったものを、読んだことにしない。** `abstract-only` / `unverified` を明記する。
5. **証拠の分布を、論争の有無と混同しない。** 「議論がある」は「証拠が半々」ではない。
6. **統合のたびに、判断の来歴を残す。** 検索語、スクリーニング基準、除外理由、抽出値、変換式。

---

## 1. 資料の種類と優先順位

| 層 | 例 | 使い方 | 注意 |
|---|---|---|---|
| 一次 | 実験、調査原票、法令、統計、公文書、当事者証言、査読論文の原データ | 根拠の中心 | 全文・方法・付録を読む |
| 二次 | レビュー論文、メタ分析、解説記事、専門書 | 地図、用語整理、引用の遡り | 引用元を確認。二次の結論を一次の代わりにしない |
| 三次 | 百科事典、まとめサイト、SNS、生成AIの要約 | 入口、用語の確認 | 根拠にしない |

**資料の適格性**：問いとの関係（core / supporting / context / counter）、デザイン、集団、時代、地域、利害関係。

## 2. 読解の3パス

### Pass 1 — 地図（5〜10分）

- 問い、結論、構成、分野内の位置づけ。
- 著者が何と戦っているか（先行研究の何を否定・拡張するか）。
- 自分の問いに関係する節・図表・付録の場所をマークする。
- 読む必要のない節を決める。全部を均等に読まない。

### Pass 2 — 検証（20〜60分）

- 方法：デザイン、サンプル、募集、割付、測定、比較、統計、欠測。
- 結果：主要アウトカム、効果量、区間、サブグループ、感度分析。
- 限界：著者が認めている限界と、認めていない限界。
- 利害：資金、著者の立場、利益相反、再現性、撤回。
- 引用している一次資料のうち、自分の主張に必要なものを開く。

### Pass 3 — 抽出（10〜20分）

- 自分の記事で使う主張・数値・引用を、頁・節・表・図番号付きで抜く。
- 主張タイプ（記述・因果・予測・機制・評価・解釈・概念・政策）を付ける。
- その主張を支える根拠（Warrant）を1文で書く。
- 反証・反例・矛盾をメモする。
- 不明点を `【未確認：〜】` として残す。

### 読解カード（1資料1枚）

```markdown
## S01 — 書誌
- 問い:
- デザイン / サンプル / 期間 / 場所:
- 主要結果（効果量・区間・分母）:
- 著者の結論:
- 限界（著者申告）:
- 限界（こちらが見つけたもの）:
- 利害関係:
- 引用可能な主張:
- 反証・矛盾:
- 検証状態: verified / partial / abstract-only / secondary-only / unverified / retracted
- 読んだ範囲: 全文 / 方法と結果 / 抄録のみ
```

## 3. チャンク読解と長文脈

長い資料を一度に読めない場合：

1. **見出しマップ**を作る。各節の仕事を1行で書く。
2. 問いに関係する節だけを読む。関係しない節は「範囲外」と記録する。
3. 節ごとに「主張カード」（主張・証拠・頁・確信度）を作る。
4. カードを統合し、重複・矛盾・依存関係を整理する。
5. 元の文脈に戻って確認する。要約だけで引用しない。

**チャンク間の矛盾**は、無視せず `contradictions.md` に残す。

## 4. 出典の独立性与と証拠の数え方

### 4.1 独立でない例

- 同じデータセットの複数論文。
- 同じ著者グループの連作。
- 二次資料が同じ一次資料を引用している。
- メタ分析と、そのメタ分析に含まれる個別研究を別々に数える。
- プレスリリースと、その元論文。
- 同じ調査の速報値と確定値。

### 4.2 証拠の単位

- **研究単位**で数える。論文単位ではない。
- 同じ研究の複数アウトカムは、問いごとに分ける。
- サブグループ分析は、独立した証拠ではなく、同じ研究内の異質性。
- 追試（replication）は、独立した証拠になりうる。ただし、同一プロトコル・同一データでなければ。

### 4.3 引用の連鎖を遡る

1. 主張を引用している資料を開く。
2. その資料が引用している一次資料を開く。
3. 一次資料のどこに、その主張が書かれているかを確認する。
4. 主張が原典より強くなっていないか（scope creep）を確認する。
5. 原典が撤回・訂正されていないか確認する。

**引用の増殖**：同じ誤った主張が、相互引用によって「複数の証拠」に見えることがある。

## 5. 系統的レビューの手順

### 5.1 プロトコル

- 問い（PICO / PEO / SPIDER）。
- 適格基準（集団、介入・現象、比較、アウトカム、デザイン、言語、期間）。
- 検索戦略（データベース、検索語、フィルタ、検索日）。
- スクリーニング（独立2名、不一致の解消）。
- 抽出（独立2名、パイロット）。
- バイアス評価（RoB 2、ROBINS-I、MMAT、CASP など）。
- 統合方法（量的・質的・物語）。
- 確信度（GRADE、CERQual）。
- 変更履歴。

### 5.2 検索（PRISMA-S）

- 複数のデータベース（例：PubMed, Web of Science, Scopus, PsycINFO, CiNii, Google Scholar は補助）。
- 検索語のブロック（集団 AND 現象 AND デザイン）。
- 統制語（MeSH など）と自由語。
- 灰色文献（政府、国際機関、学位論文、会議録）。
- 反証探索：`criticism`, `replication failure`, `null result`, `retraction`, `conflict of interest`。
- 検索ログに、日付・件数・式を残す。

### 5.3 スクリーニング

- タイトル・抄録 → 全文。
- 除外理由をカテゴリ化して数える。
- 独立2名、不一致は協議。κ を記録する（任意）。
- PRISMA 2020 のフロー数（同定・スクリーニング・適格・採用）。

### 5.4 バイアス評価

- **RoB 2**：ランダム化試験（割付、逸脱、欠測、アウトカム測定、報告）。
- **ROBINS-I**：非ランダム化介入研究（交絡、選択、介入分類、逸脱、欠測、測定、報告）。
- **MMAT / CASP**：質的研究・混合研究。
- **AMSTAR 2**：レビューの質。
- 評価は「低 / 中 / 高 / 深刻」などで行い、根拠を書く。

### 5.5 エビデンス表

| ID | 研究 | デザイン | 集団 | n | 介入/比較 | 主要結果 | 効果量 (95%CI) | バイアス | 直接性 |
|---|---|---|---|---|---|---|---|---|---|

表は本文の要約ではなく、判断の根拠である。本文と表の数値が一致するか確認する。

## 6. 量的統合

### 6.1 効果量

- 連続：平均差（MD）、標準化平均差（SMD / Cohen's d, Hedges' g）。
- 二値：リスク比（RR）、オッズ比（OR）、リスク差（RD）、NNT。
- 時間：ハザード比（HR）。
- 相関：r、Fisher's z。
- 変換は式と出典を記録する。尺度の向きを揃える。

### 6.2 モデル

- **固定効果**：共通の真の効果を仮定。研究間の異質性が小さいとき。
- **ランダム効果**：研究間の効果分布を仮定。異質性を許容。
- **三レベル / マルチレベル**：同じ研究内の複数効果量を扱う。
- **頑健分散推定（RVE）**：依存する効果量を扱う。

### 6.3 異質性

- Cochran's Q、I²、τ²、予測区間。
- I² は「研究間のばらつきの割合」であり、効果の大きさではない。
- 異質性が高い場合、平均効果の解釈を限定する。サブグループ・メタ回帰で説明を試みる。
- 説明できない異質性は、結論の適用範囲を狭める。

### 6.4 出版バイアス

- ファンネルプロットの非対称。
- Egger 検定、Begg 検定（検出力が低い）。
- trim-and-fill（補正の推定）。
- PET-PEESE（効果量と標準誤差の関係）。
- 否定的結果の不在、小規模研究の過大効果、利益相反。

### 6.5 感度分析

- 外れ値を除く。
- バイアス高の研究を除く。
- 固定効果とランダム効果を比較。
- 未発表研究を仮定して追加する。
- 結論が変わるかを報告する。変わらなければ頑健、変われば条件付き。

### 6.6 やってはいけないこと

- 異質性を無視した単純平均。
- 効果量の捏造・変換ミス・二重計上。
- 研究数が少ないのにメタ分析を必須とする。
- p 値を都合よく再計算する。
- サブグループ分析を「発見」として報告する（探索的であると明記）。
- 統計的有意性を、実務的重要性と混同する。

## 7. 質的統合

- **テーマ分析**：コード → サブテーマ → テーマ。文献の要約ではなく、意味のパターン。
- **フレームワーク合成**：既存の理論・政策枠組みに沿って配置し、適合しない知見を残す。
- **メタエスノグラフィー**：概念の翻訳（translation）と線の合成（line-of-argument）。
- **リアリスト評価**：機制（mechanism）＋文脈（context）＋結果（outcome）の配置。
- **CERQual**：方法の限界、一貫性、直接性、データの十分性。

質的証拠は「弱い量的証拠」ではない。意味・プロセス・文脈を扱う別の種類の証拠である。一般化ではなく、転用可能性（transferability）を論じる。

## 8. 合意・不一致・空白

### 8.1 合意の書き方

「多くの研究が一致して X を示す」と書く前に：

- 独立した研究か。
- 効果の方向・大きさ・集団が同じか。
- 出版バイアスの可能性。
- 反対結果の有無。
- 合意の範囲（どの集団・条件で）。

### 8.2 不一致の書き方

- 結果の不一致：デザイン、集団、用量、期間、測定、分析。
- 解釈の不一致：理論、前提、モデル。
- 価値の不一致：何を重要と見るか。
- どれが証拠で、どれが解釈かを分ける。

### 8.3 空白（gap）の書き方

「研究がない」は、次のいずれかである。

- 本当に未研究（検索で確認）。
- 研究があるが、自分の検索では見つからない。
- 研究が難しい（倫理・データ・費用）。
- 研究はあるが、別の用語・分野で呼ばれている。

**空白の主張には、検索範囲と限界を付ける。** 「先行研究はない」と断定しない。

## 9. 文献レビューの構成

### 9.1 テーマ統合型（人文・社会科学）

```text
1. 問いと範囲
2. 用語と概念の整理
3. テーマ1：何が言われてきたか（合意）
4. テーマ2：対立（不一致とその理由）
5. テーマ3：見落とし（空白）
6. 方法論の批判（デザイン・測定・サンプル）
7. 総合：現時点で言えること / 言えないこと
8. 含意（理論・実務・政策）
9. 限界
```

### 9.2 系統的レビュー（PRISMA 2020）

```text
1. 背景と問い（PICO）
2. 方法（プロトコル、検索、適格基準、スクリーニング、抽出、バイアス、統合）
3. 結果（PRISMA フロー、研究特性、バイアス、統合結果）
4. 考察（確信度、限界、含意）
5. 結論
```

### 9.3 書かないこと

- 論文ごとの要約の列挙。
- 「多くの研究がある」だけの記述。
- 引用の飾り（主張を支えていない引用）。
- 反対証拠の無視。
- 検索範囲を書かない「網羅的」の主張。
- 抄録だけ読んで効果量を断定すること。

## 10. 主張の強さと確信度の伝播

| 証拠の状態 | 許される主張 | 許されない主張 |
|---|---|---|
| 複数の独立した RCT / 再現 | 「効果がある」「〜を増やす」 | 「唯一の原因」「すべての場合」 |
| 1つの RCT / 強い準実験 | 「〜の可能性が高い」「〜と整合する」 | 「証明された」「一般に〜だ」 |
| 観察研究の一致 | 「〜と関連する」「〜を予測する」 | 「〜が原因だ」 |
| 横断研究 | 「〜と相関する」 | 「〜が〜を引き起こす」 |
| 質的研究 | 「〜という経験・意味がある」 | 「〜が一般的だ」 |
| 事例 | 「〜という事例がある」 | 「〜が典型だ」 |
| モデル | 「モデルは〜を示唆する」 | 「現実に〜が起きる」 |
| 専門家の意見 | 「〜と主張されている」 | 「〜が実証された」 |
| 未確認 | `【未確認】` | 断定 |

**確信度の伝播**：結論は、最も弱い荷重前提より強くしない。複数の証拠を足しても、弱点は消えない（弱い鎖は足しても強くならない）。

## 11. マルチエージェント読解

多数の資料を読むときは、役割を分ける（詳細は `orchestration.md`）。

1. **Librarian**：検索、書誌、重複排除、検索ログ。
2. **Extractor**：1資料1カード。主張・証拠・頁・限界。
3. **Methodologist**：デザイン、バイアス、統計。
4. **Synthesizer**：テーマ統合、証拠の独立性、矛盾の整理。
5. **Auditor**：引用の照合、数値の一致、主張の強さ。

**統合のルール**

- 抽出カードには資料IDを必須にする。IDのない要約は捨てる。
- 同じ主張でも、資料ごとに確信度を付ける。
- エージェント間の不一致は、多数決で消さず、`contradictions.md` に残す。
- 統合者は一次資料を開かずに断定しない。必要なら原本に戻る。

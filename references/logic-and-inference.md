# 論理・推論エンジン

> 読むタイミング：Phase 2.5（推論の設計）、Phase 3（論証の構築）、Phase 5（赤チーム監査）。
> この文書は「正しい結論」を配るものではない。**前提から結論への移り方が、どこまで支えられているかを点検する**ための手順である。

---

## 0. 基本姿勢

1. **論理は、前提が真であることを保証しない。** 妥当な論証でも、前提が偽なら結論は偽になりうる。
2. **妥当性と説得力は別である。** 妥当でも信じられない論証はある。説得的でも不正な論証はある。
3. **形式を整えることは、内容を強くすることではない。** 記号化は曖昧さを減らすが、経験的前提の真偽は決めない。
4. **反論可能性を歓迎する。** 反証条件のない主張は、論証ではなく宣言である。
5. **わからないことを、わかった形にしない。** 前提が足りないなら「不足している」と書く。これは論理の敗北ではなく、正確さである。

## 1. 論証の再構成

### 1.1 何が論証か

論証は「理由（前提）から結論を導く発話」である。次のものは論証ではない。

- 説明（なぜ起きたかの記述。結論は既に受け入れられている）
- 記述（事実の列挙）
- 主張の繰り返し
- 例示（結論の一例を示しているだけ）
- レトリック（比喩、問いかけ、感情表現）

**見分け方**：その文を「だから」でつなぐと意味が通るか。「A。だから B。」が通れば、A は B の理由候補である。

### 1.2 標準形への再構成

1. 結論を1文で特定する。手がかりは「したがって」「だから」「故に」「so」「therefore」「hence」「よって」。
2. 明示された前提を列挙する。手がかりは「なぜなら」「というのも」「since」「because」。
3. 暗黙の前提（enthymeme）を補う。ただし**補いすぎない**。
4. 各前提に由来タグを付ける。
   - `[TEXT]` 原文に明示されている
   - `[CONV]` 分野の慣例・定義から当然に補える
   - `[ANALYST]` 分析者が補った。論証の評価はこのタグに依存する
5. 結論が複数ある場合は、主結論と中間結論を分ける。
6. 論証の「狙い」を1文で書く。相手が本当に示したいこと。

### 1.3 補完の上限（charity ceiling）

善意の解釈（principle of charity）は必要だが、**論者が言っていない論証に作り替えてはいけない**。

- 補った前提が結論を支えるために不可欠なら、その旨を明示する。
- 候補前提は1つに決めず、2〜3個併記する。
- 補完によって論証が強くなりすぎる場合、その強さは `[ANALYST]` の産物である。
- 「この前提を補わない限り、論証は成立しない」と書くのは、批判として有効である。

### 1.4 再構成の出力例

```text
結論 C: 都市部の路上駐車料金は引き上げるべきだ。
P1 [TEXT]: 路上駐車は交通渋滞を悪化させる。
P2 [CONV]: 渋滞の社会的費用は、駐車利用者が支払う料金に含まれていない。
P3 [ANALYST]: 外部費用を料金に内部化するのが妥当である。
∴ C
弱点: P3 は「妥当」の規範的前提であり、実証では決まらない。
```

## 2. 演繹

### 2.1 妥当な形式

| 形式 | 形 | 例 |
|---|---|---|
| 肯定式 (Modus Ponens) | P→Q, P ∴ Q | 雨なら中止。雨だ。∴ 中止。 |
| 否定式 (Modus Tollens) | P→Q, ¬Q ∴ ¬P | 雨なら中止。中止しない。∴ 雨でない。 |
| 仮言三段論法 | P→Q, Q→R ∴ P→R | |
| 選言三段論法 | P∨Q, ¬P ∴ Q | |
| 構成的両刀 | (P→Q)∧(R→S), P∨R ∴ Q∨S | |
| 単純化 | P∧Q ∴ P | |
| 連言 | P, Q ∴ P∧Q | |
| 付加 | P ∴ P∨Q | |

### 2.2 不正な形式（頻出）

| 誤り | 形 | なぜ誤りか |
|---|---|---|
| 後件肯定 | P→Q, Q ∴ P | Q の原因が他にもある |
| 前件否定 | P→Q, ¬P ∴ ¬Q | P でなくても Q は起こりうる |
| 非分配の中項 | すべて A は B、すべて C は B ∴ すべて A は C | 中項 B が分配されていない |
| 選言の誤用 | P∨Q, P ∴ ¬Q | 両方成り立つ可能性 |
| 条件の混同 | P→Q ∴ Q→P | 逆は真ならない |
| 誤った選言 | P∨Q を排他的と解釈 | 包括的選言かもしれない |

### 2.3 必要条件と十分条件

- 「P ならば Q」= P は Q の**十分条件**、Q は P の**必要条件**。
- 「Q でなければ P でない」= Q は P の必要条件。
- 「P のとき、かつそのときに限り Q」= 必要十分条件。

**頻出の誤り**

1. 必要条件を十分条件として扱う（「免許がなければ運転できない。免許がある。∴ 運転できる」）。
2. 十分条件を必要条件として扱う（「罰金を払えば解決する。罰金を払わない。∴ 解決しない」）。
3. 「〜しなければならない」を「〜すればよい」にすり替える。
4. 因果の「原因」を「条件」と混同する。原因は結果の十分条件とは限らない。

### 2.4 量化子とスコープ

- `∀x (P(x) → Q(x))` は「すべての P は Q」。`∀x (P(x) ∧ Q(x))` ではない。
- `∃x (P(x) ∧ Q(x))` は「P かつ Q であるものが存在する」。`∃x (P(x) → Q(x))` はほとんどの場合に無意味に真になる。
- スコープの曖昧さ：「すべての学生は、ある本を読んだ」は、
  - 学生ごとに（同じでなくてよい）本がある `∀x∃y`
  - 全員が同一の本を読んだ `∃y∀x`
  の両方に読める。文脈で決める。
- 「例外なく」「原則として」「典型的には」を区別する。量化子の強さは主張の強さである。

### 2.5 条件文の種類

- **指示的条件**（indicative）：「もし雨なら中止する」。現実の可能性を扱う。
- **反事実的条件**（counterfactual）：「もし雨だったら中止していた」。起きなかった世界を扱う。因果推論の中心。
- **規範的条件**：「もし公平を望むなら、〜すべきだ」。価値前提を含む。

反事実を実証するには、比較可能な対照群・反事実の代理・構造的仮定が必要である。「〜だったら」の直感は証拠ではない。

### 2.6 真理表と証明の使いどころ

- 命題論理の妥当性は真理表で機械的に決まる。ただし、自然言語の条件文を完全には捉えない。
- 量化子を含む論証は述語論理で扱う。すべてを形式化する必要はない。
- **形式化が有効な場面**：条件の入れ子、選言、量化子、必要十分条件、循環。
- **形式化が無効な場面**：曖昧な概念、価値判断、文脈依存の意味、程度問題。無理に記号化すると、もっともらしいが無意味な論証ができる。

## 3. 非演繹的推論

### 3.1 帰納的一般化

- 前提：観察された N 個の A が B だった。
- 結論：A は一般に B である。
- 強さを決めるもの：サンプルの代表性、無作為性、サイズ、例外の探索、観察の質。
- **典型的な誤り**：少数例からの一般化、生存者バイアス、便利なサンプル、多重比較の結果を「発見」と呼ぶ。

### 3.2 アナロジー

- 前提：A と B は性質 p, q, r を共有する。A は s を持つ。
- 結論：B も s を持つ可能性が高い。
- 強さを決めるもの：共有性質の関連性、類似の深さ（表層か構造か）、異なる性質の数、結論の範囲。
- **手順**：対応関係を列挙する → 構造的類似か表面的類似かを判定する → 壊れる境界を探す → 結論を弱める。
- アナロジーは発見には強いが、証明には弱い。

### 3.3 最良説明への推論（IBE / abduction）

- 観察 O がある。仮説 H が O を最もよく説明する。∴ H が真である可能性が高い。
- 評価基準（説明的美徳）：
  1. **説明力**（どれだけの観察を説明するか）
  2. **深さ**（表面だけでなく機制を説明するか）
  3. **予測力**（新しい観察を導くか）
  4. **反証可能性**（何が起きたら崩れるか）
  5. **節度**（主張が観察を超えていないか）
  6. **単純性**（不要な存在者・過程を増やさないか）
  7. **保守性**（確立した知識との整合）
- **誤り**：もっともらしい物語を最良説明と混同する。説明できることと、証拠があることは違う。

### 3.4 因果的推論

「A が B を引き起こした」は、単なる相関以上のものを主張する。詳細は §5。

### 3.5 統計的推論

- サンプルから母集団への推論は、サンプリング設計に依存する。
- p 値は「帰無仮説の下で、観察以上に極端なデータが得られる確率」である。事後確率でも効果の大きさでもない。
- 信頼区間は、推定の不確実性を表す。区間の端が臨床的・実務的に重要かを見る。
- 効果量（d, g, r, OR, RR, HR, NNT）を、単位・尺度・集団とセットで報告する。
- 検出力が低い研究の非有意は、「効果がない」証拠として弱い。
- 多重比較・p-hacking・HARKing・出版バイアスを疑う。

## 4. 確率と不確実性

### 4.1 確率の解釈

- **頻度主義**：長期的な相対頻度。
- **ベイズ主義**：信念の度合い。事前分布を更新する。
- **傾向性**：物理的・統計的傾向。

記事では、どの解釈かを明示する。特に「確率80%」は、頻度か信念かで意味が違う。

### 4.2 ベイズの基本

```text
P(H|E) = P(E|H) P(H) / P(E)
P(E) = P(E|H)P(H) + P(E|¬H)P(¬H)
```

- `P(H)` 事前確率
- `P(E|H)` 尤度（H の下で E が起こる確率）
- `P(H|E)` 事後確率
- `P(E|¬H)` 誤警報率

**オッズ形式**：

```text
事後オッズ = 事前オッズ × 尤度比
尤度比 = P(E|H) / P(E|¬H)
```

### 4.3 基礎率の無視

検査精度が高くても、疾患の基礎率が低ければ、陽性の大半は偽陽性になりうる。

例：有病率 0.1%、感度 99%、特異度 99% のとき、
- 陽性者 10,000 人中：真陽性 ≈ 10、偽陽性 ≈ 100。
- 陽性の約 9% だけが真の疾患。

**記事で使うとき**：感度・特異度だけでなく、有病率（事前確率）と検査前確率を書く。

### 4.4 よくある確率誤謬

| 誤謬 | 内容 | 防ぎ方 |
|---|---|---|
| 基礎率の無視 | 精度だけを見て事後確率を過大評価 | 自然頻度で計算する |
| 連言錯誤 | 「A かつ B」を「A」より確からしいと判断 | 連言は単独より確率が低い |
| 検察官の誤謬 | P(E|H) と P(H|E) を混同 | ベイズで向きを確認 |
| 逆確率の誤謬 | 感度を陽性率と混同 | 分母を確認 |
| ギャンブラーの誤謬 | 独立試行の結果が過去に依存すると考える | 独立性を確認 |
| 平均への回帰 | 極端な観察の次は平均に近づく | 対照群なしの改善を効果と呼ばない |
| 生存者バイアス | 生き残ったものだけを見る | 脱落・失敗例を探す |
| 非可視化の証拠 | データがないことを「効果なし」とする | 「検出できなかった」と書く |

### 4.5 較正（calibration）

| 言い方 | 意味の目安 | 使える条件 |
|---|---|---|
| 確実 | 99%以上 | 論理的必然、または極めて強い反復証拠 |
| ほぼ確実 | 90〜99% | 複数の独立した強い証拠 |
| 高い確度 | 75〜90% | 質の高い研究の一致 |
| 示唆する | 55〜75% | 限定的・間接的な証拠 |
| 可能性がある | 30〜55% | 弱い証拠、機制の推測 |
| 不明 | 判断不能 | データ不足 |

数字を本文に書く必要はない。しかし、**言葉の強さを確率の目安に合わせる**。読者が「示唆する」を「証明した」と読む書き方をしない。

### 4.6 期待値と意思決定

```text
EV = Σ p_i × v_i
```

- 確率と価値（効用）を分けて見積もる。
- 破滅的リスク（吸収状態）は期待値では扱えない。最大損失・回復可能性を別に見る。
- 不確実性が大きいときは、期待値より**頑健性**（最悪ケースでも許容できるか）を優先する。
- 情報の価値（value of information）＝ 追加調査で意思決定が変わる可能性 × 変更の便益 − 調査コスト。

## 5. 因果推論

### 5.1 因果主張の種類

| 種類 | 問い | 必要なもの |
|---|---|---|
| 効果の存在 | A は B を変えるか | 反事実の比較 |
| 効果の大きさ | どれだけ変えるか | 効果量と区間 |
| 効果の異質性 | 誰に、どんな条件で効くか | 交互作用・サブグループ |
| 機制 | どうやって効くか | 媒介分析・理論・実験 |
| 外部妥当性 | 別の集団・文脈でも成り立つか | 一般化の根拠 |

「効果がある」と「機制がわかった」は別である。予測精度は機制の証明ではない。

### 5.2 因果グラフ（DAG）の基本

- **交絡（confounder）**：A と B の両方に影響し、見かけの関連を作る。
- **媒介（mediator）**：A → M → B。媒介を調整すると総効果が消えることがある。
- **コライダー（collider）**：A → C ← B。C で条件づけると、A と B に偽の関連が生じる。
- **選択（selection）**：生存・参加・脱落によって生じるバイアス。

**バックドア基準**：A と B の間のすべてのバックドア経路を塞ぐ変数集合を調整する。ただし、コライダーや媒介を闇雲に調整しない。

### 5.3 識別戦略と仮定

| デザイン | 何を利用するか | 主要な仮定 | 典型的な脅威 |
|---|---|---|---|
| RCT | 無作為割付 | 割付の無作為性、遵守、脱落の独立 | 非遵守、ATT の限定、外部妥当性 |
| 自然実験 | 外生的ショック | ショックの外生性、除外制約 | 交絡、予期、同時ショック |
| 差分の差分 (DiD) | 処置群と対照群の変化 | 平行トレンド | トレンドの違い、同時政策 |
| 回帰不連続 (RD) | 閾値の前後 | 閾値付近の連続性、操作なし | 操作、関数形、局所性 |
| 操作変数 (IV) | 外生変数 | 関連性、除外制約、単調性 | 弱い操作変数、除外制約違反 |
| マッチング | 観察可能変数 | 条件付き独立、共通サポート | 未観測交絡、モデル依存 |
| 固定効果 | 単位内変化 | 時不変の交絡を除去 | 時間変化する交絡、逆因果 |

**共通の原則**：どのデザインも、仮定が破れたときのバイアスの向きと大きさを検討する。感度分析（Rosenbaum bounds、E-value、 placebo test、pre-trend test）を行う。

### 5.4 因果言語のはしご

| 証拠 | 許される表現 | 避ける表現 |
|---|---|---|
| RCT の一致した結果 | 「〜を増やす」「〜に因果効果がある」 | 「〜が唯一の原因」 |
| 自然実験・準実験 | 「〜と整合する因果効果」「〜をもたらす可能性が高い」 | 「証明された」 |
| 観察研究の縦断データ | 「〜と関連する」「〜を予測する」 | 「〜が原因だ」 |
| 横断研究の相関 | 「〜と相関する」「〜と同時に観察される」 | 「〜が〜を引き起こす」 |
| 事例・証言 | 「〜という事例がある」 | 「一般に〜だ」 |
| モデル・シミュレーション | 「モデルは〜を示唆する」 | 「現実に〜が起きる」 |

### 5.5 「効果なし」の正しい書き方

- 非有意 → 「統計的に有意な差は検出されなかった」。
- 信頼区間が狭く、重要効果を排除 → 「実務的に意味のある効果は考えにくい」。
- 信頼区間が広い → 「効果の有無は不明。より大きな研究が必要」。
- 検出力不足 → 「この研究では検出できなかった」。効果がない証明ではない。

### 5.6 因果と規範を混ぜない

「X が Y を増やす」は記述。「X を規制すべきだ」は規範。後者には、価値前提（何を望ましいとするか、誰の負担を許容するか）が必ず入る。§7 と `normative-and-conceptual.md` を参照。

## 6. 証拠の統合

### 6.1 独立した証拠か

同じデータ・同じ著者・同じ引用元を共有する研究は、独立した証拠ではない。**引用の連鎖**を遡り、一次データに到達する。

- 二次資料が一次資料を引用しているだけなら、証拠は1つ。
- 同じデータセットを使った複数論文は、独立した追試ではない。
- メタ分析に含まれる研究の重複を確認する。
- 引用の増殖（citation laundering）を疑う。

### 6.2 証拠の格付け

デザインのラベルではなく、次の5軸で評価する（GRADE 的発想）。

1. **バイアスリスク**（選択、測定、交絡、脱落、報告）
2. **非一貫性**（結果のばらつき、説明できない異質性）
3. **非直接性**（集団、介入、比較、結果が問いとずれる）
4. **不精確さ**（参加者数、イベント数、信頼区間）
5. **出版バイアス**（否定的結果が出にくい）

### 6.3 定量統合の最低条件

- 効果量が共通の尺度に変換できる。
- 研究間の臨床的・方法論的異質性が許容範囲。
- 研究数が少なすぎない（目安：5本未満なら統合を慎重に）。
- 出版バイアスを評価できる（ファンネルプロット、Egger、trim-and-fill、PET-PEESE）。
- 感度分析（外れ値、固定効果 vs ランダム効果、リスクオブバイアス除去）を行う。
- 統合結果の不確実性（予測区間）を報告する。

**禁止**：異質性を無視した単純平均、都合の良い研究だけの統合、効果量の捏造、p 値の再計算の偽装。

### 6.4 質的統合

- テーマ統合：コード → サブテーマ → テーマ。研究ごとの要約を並べない。
- フレームワーク統合：既存理論の枠に当てはめ、適合しないものを残す。
- メタエスノグラフィー：概念の翻訳と統合。文脈の厚みを失わない。
- CERQual：質的証拠の信頼性（方法の限界、一貫性、直接性、十分性）。

### 6.5 不一致の扱い

不一致には3種類ある。

1. **証拠の不一致**（結果が違う）→ デザイン、集団、測定、時期の違いを検討。
2. **解釈の不一致**（同じ結果を違う意味に読む）→ 理論的枠組みと前提を比較。
3. **価値の不一致**（同じ事実から違う結論）→ 価値前提を明示し、合意可能な部分を探す。

「議論が続いている」は「証拠が半々」ではない。**論争の存在は、証拠の分布とは別**である。

## 7. 競合仮説と反証

### 7.1 競合仮説分析（ACH）

1. 仮説を列挙する（H1…Hn）。互いに排他的でなくてよい。
2. 証拠を列挙する（E1…Em）。
3. 行列を作る。各セルを「整合」「不整合」「中立」で評価する。
4. **診断的証拠**（仮説間で評価が分かれる証拠）を特定する。
5. 最も反証が少ない仮説を暫定採用する。支持が最も多い仮説ではない。
6. 反証を説明するための補助仮説（ad hoc rescue）を数える。多いほど脆弱。

### 7.2 反証条件

各荷重主張に、次を書く。

- どの観察が起きたら主張を撤回するか。
- どの観察が起きたら主張を弱めるか。
- どの観察が起きても主張が変わらないなら、それは反証不可能である。

**反証不可能な主張**は、経験的主張として扱えない。定義・価値・論理的帰結として書き直す。

### 7.3 反論の強さ

- **最強の反論（steelman）**：相手が読んでも「それだ」と思う形。
- **代替説明**：交絡、逆因果、選択、測定誤差、偶然、回帰。
- **フレーム批判**：問いの前提、選択肢の設定、評価基準そのものを疑う。
- **実装批判**：制度・費用・インセンティブ・副作用・分布効果。

弱い反論を3つ並べても、強い反論1つには勝てない。

### 7.4 反論への応答

1. 反論を要約し、相手に確認を求める形で書く。
2. 譲れる点を先に譲る。
3. 譲れない点は、証拠・論理・価値前提のどこで対立しているかを特定する。
4. 反論が正しければ結論を変える。**結論を守るために証拠を曲げない。**

## 8. 誤謬の分類と修復

> 誤謬は「間違った内容」ではなく「理由づけの型の失敗」である。誤謬名を貼ることが目的ではない。**どこで移り方が壊れたかを言い、修復案を出す**。

### 8.1 関連性の誤謬（結論と理由がつながらない）

| 誤謬 | 見分け方 | 誤謬でない場合 | 修復 |
|---|---|---|---|
| 人身攻撃 | 相手の人格・所属で主張を退ける | 信用性が論点（証言の真偽） | 主張と証拠を分離して評価 |
| 感情への訴え | 恐怖・同情で結論を導く | 感情が道徳的考慮の一部 | 事実と価値を分ける |
| 権威への訴え | 専門家の言のみで結論 | 分野の専門家で、根拠も示す | 根拠と合意の範囲を確認 |
| 衆人への訴え | 多数が信じるから真 | 多数の経験が証拠になる場合 | 世論と真偽を分ける |
| ストローマン | 相手の主張を弱く言い換える | 相手の実際の主張 | 最強版で再構成 |
| 赤いニシン | 論点をずらす | 文脈上関連する | 問いに戻す |
| 汝も同じ | 相手の矛盾で主張を退ける | 一貫性が規範的論点 | 主張の真偽と行為者を分ける |

### 8.2 弱い帰納の誤謬

| 誤謬 | 見分け方 | 誤謬でない場合 | 修復 |
|---|---|---|---|
| 早すぎる一般化 | 少数例から一般化 | サンプルが代表的 | 範囲を限定、サンプルを増やす |
| 無知に訴える | 証明がないから真/偽 | 立証責任が適切に分配 | 立証責任を明示 |
| 権威でない権威 | 専門外の権威 | 学際的知見 | 専門性と根拠を確認 |
| 誤った原因 | 前後・同時で因果 | 機制と対照群がある | 反事実を検討 |
| 滑坡 | 連鎖の各段の証拠がない | 各段が確実で機制がある | 各段の確率を書く |
| 少量のデータ | 小標本の極端値 | 効果量が大きい | 区間と再現を確認 |

### 8.3 不当な前提の誤謬

| 誤謬 | 見分け方 | 誤謬でない場合 | 修復 |
|---|---|---|---|
| 循環論法 | 結論を前提に使う | 定義の循環（別問題） | 独立した根拠を探す |
| 偽のジレンマ | 二択を強制 | 本当に二択 | 第三・第四の選択肢 |
| 複合質問 | 前提を質問に埋め込む | 前提が合意済み | 前提を分離 |
| 証拠の隠蔽 | 都合の悪い証拠を無視 | 範囲外と明示 | 反対証拠を追加 |
| 付属性・合成 | 部分の性質を全体へ | 全体が部分に還元できる | レベルを分ける |

### 8.4 言語の誤謬

| 誤謬 | 見分け方 | 誤謬でない場合 | 修復 |
|---|---|---|---|
| 多義性 | 同じ語を違う意味で使う | 意図的な言葉遊び | 定義を固定 |
| 強調の操作 | 文脈を切って引用 | 引用が正確 | 全文脈を確認 |
| 曖昧な枠組み | 比喩を論証に使う | 比喩が説明の補助 | 機制を言葉で説明 |

### 8.5 確率・統計の誤謬

基礎率の無視、連言錯誤、検察官の誤謬、逆確率、ギャンブラーの誤謬、平均への回帰、生存者バイアス、多重比較、p-hacking、非有意＝効果なし、有意＝重要、相対リスクと絶対リスクの混同。

**相対リスクの落とし穴**：「リスクが50%増」は、基礎率が2%なら2%→3%。分母と絶対差を書く。

### 8.6 価値・規範の誤謬

| 誤謬 | 内容 | 修復 |
|---|---|---|
| 事実から価値（is-ought） | 〜である ∴ 〜すべきだ | 価値前提を明示 |
| 自然主義的誤謬 | 自然だから善い | 「自然」の意味と価値判断を分離 |
| 伝統への訴え | 昔からそうだから正しい | 伝統の機能と正当化を分ける |
| 相対主義の誤用 | 文化が違うから評価できない | 共通の最低限の規範を検討 |
| 完全主義 | 完全でないから不可 | 比較可能な代替案で評価 |
| 滑りやすい規範 | 一度許せば全部許す | 境界と手続きを設計 |

## 9. 意思決定と政策の論理

### 9.1 意思決定の構造

1. 目的（何を最大化・遵守するか）
2. 選択肢（現状維持を含める）
3. 結果（確率と価値）
4. 制約（予算、法、権利、時間）
5. 不確実性（シナリオ、感度）
6. 不可逆性（後戻りできるか）
7. 分配（誰が受益し、誰が負担するか）

### 9.2 よくある失敗

- 現状維持を「費用ゼロ」と扱う（現状にも費用と受益者がいる）。
- 平均だけを見て分布を見ない（一部に極端な負担）。
- 期待値だけで破滅的リスクを扱う。
- 沈没費用を意思決定に含める。
- 目的と手段を混同する（「AI 導入」が目的化）。
- 政策の実施能力・インセンティブ・副作用を無視する。
- 比較対象のない「効果」を主張する。

### 9.3 政策論証の型

```text
1. 問題の定義（誰の、どの状態が、なぜ問題か）
2. 現状の説明（原因、規模、趨勢）
3. 介入の選択肢（現状維持、規制、補助、情報、再分配）
4. 効果の証拠（因果、外部妥当性、規模）
5. 費用と便益（財政、機会費用、分配）
6. 実施（法、行政能力、インセンティブ、監視）
7. 副作用と倫理（権利、自由、平等、正統性）
8. 不確実性と撤退条件
9. 推奨と条件
```

### 9.4 規範的評価の基準

- **帰結**：総便益、優先主義、NNT、QALY、分配。
- **義務・権利**：人格の尊重、約束、所有権、手続的公正。
- **徳・関係**：ケア、信頼、誠実、共同体。
- **正統性**：決定プロセスへの参加、説明責任、透明性。
- **実行可能性**：法制度、予算、行政能力、政治的持続性。

単一の基準で結論を出さない。基準間の衝突を明示する。

## 11. 限界

- 論理は、前提の真偽を決めない。事実確認は別工程である。
- 形式化は、自然言語の意味の曖昧さを完全には解消しない。
- 誤謬検出は、文脈を読まないと誤検知する。**誤謬名の指摘は、修正案とセットで初めて有用**である。
- 因果推論の仮定は、データだけでは検証できないことが多い。 domain knowledge と感度分析が必要である。
- 価値判断は、論理だけでは決まらない。`normative-and-conceptual.md` を使う。
- この文書の手順を踏んだからといって、結論が正しいとは限らない。人間の専門家による確認を置き換えない。

# 規範・概念エンジン — 倫理・哲学・政策・「道」の論じ方

> 読むタイミング：Phase 2.5 / Phase 3（問いが規範的・概念的なとき）、Phase 5（価値監査）。
> 対象：倫理、正義、意味、生き方、政治哲学、法哲学、政策の当否、文化と価値。
> 目的は「正解を配る」ことではなく、**価値前提を隠さず、最も強い反対立場に耐える論証を組む**ことである。

---

## 0. 最初に分ける3つの文

| 種類 | 例 | 何で決まるか | 誤り方 |
|---|---|---|---|
| 記述（descriptive） | 「日本の相対的貧困率は約15%である」 | データ | 事実の捏造、出典なし |
| 評価（evaluative） | 「その水準は高い」 | 基準（何と比べるか） | 基準の隠蔽 |
| 規範（normative） | 「政府は給付を増やすべきだ」 | 価値前提＋事実 | 事実から価値を導く、価値の押し付け |

**同じ記事に3つが混在してよい。ただし、文面上で区別する。**「〜である」「私は〜と評価する」「〜すべきだ」を混ぜない。

### 0.1 is-ought（事実から価値）

「X が自然だ」「昔からそうだ」「みんなそうしている」は、それだけでは「X が善い／〜すべきだ」を導かない。必要なのは：

1. 価値前提（何を善いとするか）
2. 事実前提（何が起きるか）
3. 橋渡しの原則（なぜその価値がこの場合に適用されるか）

**書式**：「事実 P が成り立つ。価値 V を受け入れるなら、P は V を損なう。したがって、V を重視する者は〜すべきだ。」V を明示すれば、反対者は V を争える。

### 0.2 規範的主張の3層

1. **価値**（何を大切にするか：自由、平等、ケア、繁栄、尊厳）
2. **原則**（価値をどう適用するか：比例性、透明性、自己決定、無危害）
3. **処方**（具体的な制度・行為）

処方だけを論じて、価値と原則を隠さない。処方の対立は、しばしば価値の対立である。

## 1. 主要な規範理論（道具として使う）

> 理論は「正解」ではなく、**問いの見落としを減らすレンズ**である。1つに commit せず、複数で同じ問題を見る。

### 1.1 帰結主義

- **功利主義**：総効用（幸福・選好充足）を最大化。
- **優先主義**：最も不遇な人の重みを大きくする。
- **充足主義**：十分な水準に達しているかを重視。
- **問い**：誰がどれだけ受益・負担するか。代替案より総合的に良いか。
- **強み**：分配と規模を比較できる。政策評価と相性がよい。
- **弱み**：権利の侵害を許しうる。効用の測定・比較が困難。少数派の犠牲を正当化しうる。
- **誤用**：効用を金銭に還元できると前提する。平均だけを見る。

### 1.2 義務論

- **カント**：人格を手段としてのみ扱わない。普遍化可能な格律。自律の尊重。
- **権利論**：侵害してはならない境界（身体、表現、所有、手続）。
- **問い**：この行為は、人を単なる手段にしていないか。誰の権利を侵害するか。一般化できるか。
- **強み**：少数者の保護、信頼、手続的公正。
- **弱み**：義務の衝突（誠実 vs 人命）。硬直化。帰結の無視。
- **誤用**：権利を絶対視して、他の権利との衝突を無視する。

### 1.3 徳倫理学

- **アリストテレス**：徳（勇気、節制、正義、実践知）と幸福（eudaimonia）。
- **問い**：この行為は、どんな人格・共同体を形成するか。実践知ある人はどう判断するか。
- **強み**：文脈、人格、関係、長期的な形成を捉える。
- **弱み**：処方が曖昧。文化依存。緊急の意思決定に弱い。
- **誤用**：「徳のある人ならこうする」で論証を省略する。

### 1.4 ケア倫理

- **問い**：誰が誰に依存しているか。関係と責任は何か。声なき声を誰が代表するか。
- **強み**：家族、介護、教育、障碍、依存関係。
- **弱み**：範囲が限定されやすい。部分性（partiality）の正当化。
- **誤用**：ケアを女性の役割に固定する。

### 1.5 契約論・公正としての正義

- **ロールズ**：無知のヴェールの下で合意される原理。基本財の分配。格差原理。
- **スキャンロン**：誰も合理的に拒否できない原則。
- **問い**：当事者が公平な立場で合意するか。最も不遇な人の立場で正当化できるか。
- **強み**：制度の正当性、分配の公平。
- **弱み**：合意の想定が現実離れ。動物・将来世代・重度障碍の包摂。
- **誤用**：無知のヴェールを特定の結論に都合よく使う。

### 1.6 ケイパビリティ

- **セン / ヌスバウム**：何をすることができ、何になることができるか（健康、教育、参加、尊厳）。
- **問い**：この制度は、誰のどのケイパビリティを広げ／狭めるか。
- **強み**：貧困・開発・障碍・ジェンダー。単なる資源配分を超える。
- **弱み**：リストの選定。測定の困難。
- **誤用**：ケイパビリティを単一指標に還元する。

### 1.7 正義・権利・共通善の複合

現実の政策は、複数理論の重なりで評価する。

| 論点 | 帰結主義 | 義務論 | 徳倫理 | ケア | 契約論 |
|---|---|---|---|---|---|
| 増税 | 再分配の便益 | 所有権・同意 | 連帯 | 依存する人への責任 | 公平な合意 |
| AI 規制 | 便益とリスク | 自律・説明責任 | 技術者の徳 | 弱い立場への影響 | 手続的公正 |
| 安楽死 | 苦痛の軽減 | 生命の不可侵 | 実践知・伴走 | 関係の負担 | 当事者の合意 |

**使い方**：1つの理論で結論を出し、別の理論で反論を検討する。理論間の不一致は、隠さず書く。

## 2. 規範的推論の方法

### 2.1 反照的均衡（reflective equilibrium）

1. 個別の直感（considered judgments）を集める。
2. 一般原則を立てる。
3. 両者が衝突する箇所を特定する。
4. 原則か直感かを修正する。
5. 安定するまで繰り返す。

**注意**：直感は文化・立場・フレーミングに影響される。直感のリストを固定しない。

### 2.2 指定（specification）と調整（balancing）

- **指定**：原則を文脈に合わせて具体化する（「表現の自由」→「暴力の扇動を除く」）。
- **調整**：衝突する原則の重みを、事情に応じて比較する。
- **比例性**：目的の正当性、手段の適合性、必要性、均衡。
- **閾値**：一定の侵害を超えたら、別の原則が優先される。

### 2.3 反例による概念の修正

- 定義 D を提示する。
- D に当てはまるが、直感では当てはまらない事例（反例）を探す。
- 必要なら D を修正する（条件の追加・除外・家族類似）。
- 反例が「直感の誤り」か「定義の誤り」かを区別する。

### 2.4 価値の多元性と不確定性

- 価値は複数あり、互いに還元できないことがある（自由と平等、効率と尊厳）。
- 比較不能（incommensurability）を認める。無理に単一尺度にしない。
- **道徳的不確定性**：どの理論が正しいかわからないとき、複数の理論で許容される行為を選ぶ（robustness）。
- **最小限の合意**：深刻な侵害を避ける、手続を公正にする、撤回可能にする。

## 3. 応用領域

### 3.1 生命倫理

4原則：自律尊重、善行、無危害、公正。

- インフォームド・コンセント（理解、自発性、能力）。
- 利益と危険のバランス。
- 脆弱な集団の保護。
- 資源配分（トリアージ、優先順位）。
- 終末期（安楽死、自殺幇助、治療中止）。
- 生殖（代理母、遺伝子編集、選別）。
- 公衆衛生（強制、監視、ワクチン）。

**注意**：医療・法務・政策の助言は、専門家の確認を前提とする。個別の診断・処方を行わない。

### 3.2 AI 倫理

- 自律（人間の制御、説明可能性）。
- 公正（バイアス、差別、分配）。
- プライバシー（監視、推論、同意）。
- 責任（誰が責任を負うか。責任の空白）。
- 透明性（開示、監査可能性）。
- 労働（置換、再訓練、尊厳）。
- 安全保障（軍事利用、自律兵器）。
- 存在リスク（過度な抽象化に注意）。

**問いの型**：誰が決定し、誰が説明し、誰が救済されるか。

### 3.3 環境・動物・将来世代

- 環境倫理：人間中心主義、生命中心主義、生態中心主義。
- 動物：苦痛の回避、種差別、食用・実験・娯楽。
- 将来世代：割引率、世代間正義、不可逆性。
- 気候：分配（排出責任、適応費用）、補償、移行。
- **注意**：自然の価値を「自然だから」で済ませない。何を守り、誰のために守るかを書く。

### 3.4 法・刑罰・戦争

- 法：法実証主義 vs 自然法。悪法の義務。
- 刑罰：応報、抑止、隔離、更生、修復。
- 戦争：正当防衛、比例性、非戦闘員の区別、先制攻撃。
- 監視：安全保障とプライバシー、令状、比例性。

### 3.5 経済・労働・教育

- 市場の限界（外部性、公共財、情報の非対称性、独占）。
- 再分配（税、給付、ベーシックインカム）。
- 労働（搾取、組合、自律、意味）。
- 教育（機会、親の権利、国家の中立、教化）。
- 住宅・医療・介護（普遍主義 vs 選別主義）。

### 3.6 文化・宗教・「道」

- **和**：調和の価値。ただし、異議申し立ての抑圧と表裏。
- **義理・人情**：関係的義務。ただし、同調圧力・腐敗の温床になりうる。
- **建前・本音**：公式の言説と実際の行動の乖離。データで確認する。
- **世間**：外部の目。規範の実効性。
- **修行・道**（武道、茶道、芸道）：実践知、身体、師弟、伝統。**本質主義に注意**。「日本的霊性」のような大きな物語で説明しない。
- **宗教**：教義、実践、共同体、政治との関係。信者を一枚岩にしない。

**文化的説明の禁止事項**：国民性・文化を単一原因にする。文化を不変とする。統計的証拠なしに「日本人は〜だ」と書く。

## 4. 政策分析

### 4.1 問題の定義

- 誰の、どの状態を、なぜ問題とするか。
- 問題の規模（人数、分布、趨勢）。
- 原因（構造、行動、制度、外部環境）。
- 問題の可視性と政治化。
- **問題定義自体が価値的判断**である（何を「問題」と見るか）。

### 4.2 選択肢

- 現状維持（費用と受益者を含む）。
- 規制、税・補助金、公共供給、情報、権利の再配分、手続改革。
- 組み合わせ。
- 実施しない理由（実行可能性、法、政治）。

### 4.3 評価基準

| 基準 | 問い |
|---|---|
| 効果 | 目的を達成するか。因果証拠はあるか。 |
| 費用 | 財政・機会費用・行政コスト。 |
| 分配 | 誰が受益し、誰が負担するか。 |
| 公平 | 手続・結果は公正か。 |
| 権利 | 侵害する権利はあるか。 |
| 実行可能性 | 法・行政能力・政治・技術。 |
| 副作用 | インセンティブ・逃避・依存・監視。 |
| 持続性 | 予算・制度・政治的支持。 |
| 可逆性 | 失敗したとき戻せるか。 |

### 4.4 証拠と価値の分離

- 効果の証拠（RCT、自然実験、パイロット）と、政策の望ましさ（価値）を分ける。
- 「効果がある」は「実施すべき」を含意しない（副作用、権利、費用）。
- 「効果がない」は「実施すべきでない」を含意しない（象徴的価値、保険、将来のオプション）。

### 4.5 政策論証のチェック

- [ ] 問題は誰の視点で定義されているか。
- [ ] 現状維持の費用を計算したか。
- [ ] 比較可能な代替案があるか。
- [ ] 効果の証拠は、この文脈に外挿できるか。
- [ ] 分配影響を書いたか。
- [ ] 権利・手続・正統性を検討したか。
- [ ] 実施能力とインセンティブを検討したか。
- [ ] 副作用と撤退条件を書いたか。
- [ ] 不確実性を明示したか。

## 5. 概念分析

### 5.1 「X とは何か」

1. 日常的な用例を集める。
2. 必要な条件を仮置きする。
3. 反例を探す（当てはまるが X でない、X だが当てはまらない）。
4. 条件を修正する。
5. 文脈依存性（法的・医学的・日常的定義）を確認する。
6. 操作的定義（測定可能な形）を提示する。

### 5.2 概念の種類

- **厚い概念**（cruel, brave, 卑怯）：記述と評価が一体化。
- **薄い概念**（good, right）：評価のみ。
- **争われる概念**（democracy, art, 家族）：本質的に論争的。
- **家族的類似**（Wittgenstein）：共通の必要十分条件がない。
- **プロトタイプ**：典型例からの距離。

### 5.3 定義の誤り

- 循環定義（「正義とは正しいことだ」）。
- 広すぎる／狭すぎる定義。
- 多義性の混同（「自由」の二義）。
- 規範的定義を記述的定義として提示する。
- 操作的定義を唯一の定義とみなす。

## 6. 思考実験

- **機能**：直感を明確化する、原則の帰結を試す、概念の境界を探る。
- **限界**：直感は文化・順序・フレーミングに依存する。現実の制度設計には追加の証拠が必要。
- **使い方**：
  1. 設定を明確にする（誰が、何を知り、何を選べるか）。
  2. 直感を述べる。
  3. 直感を支える原則を述べる。
  4. 対立する直感・原則を検討する。
  5. 現実への含意を、条件付きで書く。
- **注意**：トロッコ問題の直感を、そのまま政策の根拠にしない。

## 7. 規範的記事の書き方

### 7.1 構成

```text
1. 問い（何を、誰のために、なぜ今）
2. 事実の整理（何がわかっているか。何が争われているか）
3. 価値前提の明示（何を大切にするか。なぜか）
4. 原則の適用（比例性、権利、分配、手続）
5. 代替案の比較（現状維持を含む）
6. 最強の反論（別の価値・理論・事実）
7. 応答（譲れる点、譲れない点）
8. 結論（条件付きの処方）
9. 限界と不確実性
```

### 7.2 語彙

- 「〜すべきだ」は、条件と主体を伴わせる（「国は、〜を条件に、〜すべきだ」）。
- 「〜は善い」は、誰にとって・何の基準でかを添える。
- 「自然だ」「普通だ」「みんなそうだ」を規範の根拠にしない。
- 反対者を「無知」「悪意」と決めつけない。価値の対立として扱う。

### 7.3 反論の型

- **現実主義**：理想論だが実行できない。
- **相対主義**：文化・立場が違うので普遍化できない。
- **負担の非対称**：受益者は広く、負担者は狭い。
- ** paternalism**：本人の選択を尊重すべき。
- **滑り坂**：一度認めると際限ない。
- **制度の失敗**：行政・司法・市場が機能しない。
- **代替案**：もっと良い方法がある。

### 7.4 結論の弱め方

- 範囲を限定する（「〜の条件下では」）。
- 確信度を下げる（「〜が妥当だ」→「〜が最も妥当だと考えられる」）。
- 優先順位を付ける（「まず〜、次に〜」）。
- 手続に委ねる（「〜の合意を条件とする」）。
- 保留する（「現時点では判断できない。必要な情報は〜」）。

## 8. 価値監査（Phase 5.5）

- [ ] 事実・評価・規範を文面上で区別したか。
- [ ] 価値前提を明示したか。
- [ ] 価値前提は、読者が拒否できる形で書かれているか。
- [ ] 事実から価値を導いていないか。
- [ ] 特定の文化・宗教・立場を当然視していないか。
- [ ] 反対の価値（自由 vs 平等、効率 vs 尊厳）を公正に扱ったか。
- [ ] 分配影響（誰が負担するか）を書いたか。
- [ ] 最も弱い立場の人の視点を検討したか。
- [ ] 制度の実行可能性を検討したか。
- [ ] 結論の強さは、価値の不確定性に合っているか。
- [ ] 専門家・当事者・人間の確認が必要な領域を明記したか。

## 9. 限界

- 規範理論は、結論を一意に決めない。理論間の選択は、それ自体が価値判断である。
- 直感は証拠ではない。直感を尊重しつつ、反例と対話させる。
- 文化・宗教の記述は、内部の多様性を無視しやすい。統計と当事者の声を確認する。
- 政策の価値判断は、民主的な手続と説明責任を置き換えない。
- この文書は、法的・医療的・倫理的助言の代替ではない。重大な判断は専門家に確認する。

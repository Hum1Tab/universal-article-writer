# Research Protocol

Phase 1 の詳細。目的は「たくさん読む」ことではなく、**問いに効く証拠を、検証可能な形で集める**こと。

---

## 1. 問いを検索可能な形に分解する

検索の前に、問いを3層に分ける。

| 層 | 例（「遠隔勤務は生産性を上げるか」） |
|---|---|
| 概念 | 遠隔勤務、テレワーク、在宅勤務、ハイブリッド勤務 |
| 対象 | 職種、産業、国、期間、雇用形態 |
| 結果 | 生産性、成果、労働時間、離職、イノベーション、健康 |
| 比較 | 出社勤務、完全遠隔、ハイブリッド、導入前後 |
| 文脈 | パンデミック前後、規制、企業規模、文化 |

- 同義語・上位語・下位語・英語/現地語を列挙する。
- 略語は正式名も検索する。
- 検索式は `search-log.md` にそのまま残す。後で再現できるようにする。

---

## 2. 資料の階層

| 階層 | 種類 | 使い方 |
|---|---|---|
| 一次 | 査読論文、公式統計、法令、裁判資料、原資料、一次証言、企業の一次開示 | 主張の根拠に使う |
| 二次 | レビュー論文、専門書、調査報道、シンクタンク報告 | 地図・解釈・引用の入口に使う。可能なら一次に遡る |
| 三次 | 百科事典、まとめサイト、教科書、AI 要約 | 入口だけ。根拠にしない |

**原則**：二次資料が「X という研究がある」と言っていたら、その研究を探して一次で確認する。確認できなければ `secondary-only` と記録する。

### 分野別の主要データベース

- 医学・生命科学：PubMed, Cochrane Library, Embase, CINAHL, ClinicalTrials.gov
- 心理学・社会科学：PsycINFO, SocINDEX, SSRN, Web of Science, Scopus
- 経済・政策：EconLit, RePEc, NBER, World Bank, OECD, IMF, 各国統計局
- 人文：JSTOR, Project MUSE, MLA International Bibliography, Google Scholar
- 工学・計算機：IEEE Xplore, ACM DL, arXiv, Semantic Scholar
- 法学：HeinOnline, Westlaw, LexisNexis, 各国官報・判例データベース
- 日本：CiNii Research, J-STAGE, 国立国会図書館デジタルコレクション, e-Stat, 官公庁白書

**Google Scholar は補助**。網羅性を主張しない。アルゴリズムの順位を証拠にしない。

## 3. 検索戦略

### 3.1 広げる

- キーワードの同義語、略語、旧称、英語名。
- 引用の前後をたどる（citation chaining）。
  - 前方：その論文を引用している研究。
  - 後方：その論文が引用している研究。
- 主要なレビュー論文の参考文献リストを掘る。
- 反対側の用語で検索する。例：`minimum wage employment effects` だけでなく `minimum wage job losses criticism`。
- 灰色文献：政府報告、業界統計、NGO 報告、議会証言、企業の年次報告。
- 失敗・反証・再現不能を探す。`failed replication`, `null result`, `controversy`, `critique of`, `retraction`。

### 3.2 絞る

- 期間、言語、研究デザイン、対象、出版形態でフィルタする。
- ただし、絞りすぎて反対証拠を落とさない。除外理由を記録する。
- 査読済みとプレプリントを分ける。プレプリントは「最新だが未査読」として扱う。
- 予稿と査読版が両方ある場合は、査読版を優先し、差分を意識する。

### 3.3 反証探索（必須）

最低でも以下を1回ずつ試す。

1. **直接反証** — 「X は間違っている」「X の効果はない」。
2. **再現失敗** — `replication failure`, `failed to replicate`。
3. **代替説明** — 交絡、選択、逆因果、測定誤差。
4. **利害関係** — 資金提供、著者の所属、業界との関係。
5. **撤回・訂正** — Retraction Watch, PubMed のコメント、出版社の correction。
6. **フレーム批判** — 問いの設定自体を批判する文献。

反証が見つからなかった場合、「存在しない」と書かず、「記録した検索範囲では見つからなかった」と書く。

### 3.4 スクリーニング（全文を読む前に）

すべての資料を全文で読むと、時間が足りなくなる。まずタイトルと抄録で選別する。

| 判定 | 基準 | 次の扱い |
|---|---|---|
| `core` | 問いに直接答え、主要主張を支える | 全文を3パスで読む |
| `supporting` | 一部の論点を支える | 方法と結果を読む |
| `context` | 背景・定義・制度 | 該当箇所だけ読む |
| `counter` | 反対証拠・代替説明 | 主張と根拠を読み、反論に使う |
| `exclude` | 問いと無関係、質が低い、重複 | 除外理由を `search-log.md` に残す |

- 採用・除外の基準を、検索前に決める。後付けで変えない。
- 抄録しか読んでいない資料は `abstract-only`。
- 同じ著者・同じデータの研究は、独立した証拠として数えない。
- 除外した資料もIDを振って `search-log.md` に残す。後で必要になることがある。

## 4. 読解プロトコル

スクリーニングで `core` と判定した資料だけ、次の3パスを実行する。`supporting` 以下は、必要なパスだけを行う。

### Pass 1 — 地図（5〜10分）

- タイトル、Abstract、Introduction の最後、見出し、Discussion の最初と最後、Limitations。
- 問い、結論、主張の範囲、分野内の位置づけを1段落でメモ。
- 読む価値があるか、どの主張に使えそうかを判断する。

### Pass 2 — 検証（30〜60分）

- Methods：デザイン、サンプル、募集、介入/曝露、比較、測定、分析。
- Results：主要アウトカム、効果量、信頼区間、分母、欠測、副次アウトカム。
- Limitations：著者が認めている限界と、認めていない限界。
- 利害関係、登録、プロトコル、データ/コード公開。
- 「この研究が答えられる問い」と「答えられない問い」を分ける。

### Pass 3 — 抽出（10〜20分）

- 自分の記事で使う主張だけを、頁・節・表・図番号付きで抜く。
- 引用文は、前後の文脈ごとコピーする。切り取ると意味が変わる。
- 数値は、分母・単位・期間・集団・調整変数とセットで抜く。
- 著者の解釈と、データそのものを分けて記録する。
- 「この証拠から言えること」「言えないこと」を1行ずつ書く。

## 5. 出典台帳（`sources.csv`）

最低限の列：

| 列 | 意味 |
|---|---|
| `id` | `S01` 形式。本文の引用マーカーと一致させる |
| `type` | `journal` / `preprint` / `book` / `report` / `dataset` / `law` / `news` / `interview` / `web` |
| `title` | 原題。翻訳タイトルは別列でもよい |
| `authors` | 著者名。`et al.` で省略しない |
| `year` | 出版年 |
| `venue` | ジャーナル、出版社、媒体 |
| `doi` | DOI（あれば） |
| `url` | URL（あれば） |
| `accessed` | アクセス日 `YYYY-MM-DD` |
| `verification` | `verified` / `partial` / `abstract-only` / `secondary-only` / `unverified` / `retracted` |
| `relevance` | `core` / `supporting` / `context` / `counter` |
| `notes` | 利害関係、限界、引用箇所など |

**ルール**

- `verification=verified` は、実物を開き、書誌情報と主張の対応を確認したものだけ。
- `partial` は、実物の一部だけ確認したもの。確認できた範囲でのみ使う。
- `abstract-only` は、本文を読んでいないもの。本文の詳細な主張には使わない。
- `secondary-only` は、二次資料の記述だけを確認したもの。一次に遡れない場合に記録し、主要な根拠にしない。
- `unverified` は、実物を開いていないもの。主要な根拠にしない。
- `retracted` は引用しない。どうしても言及する場合は「撤回された研究」と明記する。
- 同じ論文のプレプリントと査読版は、別IDにしない。査読版を主IDにし、`notes` にプレプリント版を書く。

## 6. 全文アクセスと制約

### 6.1 アクセスの順序

- オープンアクセス版、機関リポジトリ、著者サイト、PMC、arXiv を探す。
- 有料文献は、抄録だけで主張を断定しない。`abstract-only` と明記する。
- 本文が読めない場合、その論文を「主要な証拠」にしない。レビュー論文や追試で補う。
- 企業・政府の都合の良い要約だけを読まない。原データ・方法論・脚注を見る。

### 6.2 PDF

- 頁番号を保持する。引用は `[S01: p.12]` の形で頁まで記録する。
- 表・図・注・補足資料を確認する。本文だけを読むと、効果量や分母を見落とす。
- テキスト抽出が崩れる場合は、該当頁を画像として読み、数字と引用句を目視で確認する。
- OCR を使った場合は、数字・人名・単位の誤認識を疑い、原頁と照合する。
- スキャン PDF は、ページ番号と本文の頁番号が一致しないことがある。両方を記録する。

### 6.3 Web

- アクセス日を記録する。重要なら Wayback Machine などでアーカイブする。
- 一次資料へのリンクをたどる。報道記事の要約だけを根拠にしない。
- 発表日と更新日を確認する。古い情報を最新として使わない。
- 同じ記事の転載（syndication）を、独立した情報源として数えない。
- 削除・改変に備え、重要な記述は引用句とアクセス日を残す。

### 6.4 機械翻訳

- 機械翻訳を使った場合は、数字と引用句を原語で確認する。
- 翻訳調の要約を、原文の引用として扱わない。
- ニュアンスが重要な箇所は、原文と訳文を併記する。

## 7. 情報源の品質チェック

### 論文

- 査読の有無。ただし査読済みでも誤りはある。
- 登録（ClinicalTrials.gov, OSF, AEA RCT Registry）とプロトコルの一致性。
- サンプルサイズ、検出力、主要アウトカムの事前指定。
- 効果量と信頼区間。p値だけを見ない。
- 多重比較、サブグループ分析、解析の自由度。
- 出版バイアス、ファイルドロワー問題。
- 再現性、データ/コード公開、利益相反。
- 撤回・訂正の有無。

### 報道・Web

- 一次資料にリンクしているか。
- 発表日と更新日。古い情報を最新として使っていないか。
- 見出しと本文の一致。本文を読むと結論が違うことがある。
- 匿名源の数と立場。単一源に依存していないか。
- 画像・動画の文脈、加工の可能性。
- 広告・PR・提携の表示。
- 同じ記事の syndication（転載）を独立源と数えない。

### 公式統計・データ

- 定義、調査方法、母集団、サンプリング、回答率、改定履歴。
- 季節調整、名目/実質、購買力平価、為替レート。
- 時系列の断絶（調査方法の変更、定義変更）。
- 速報値と確定値の区別。

### AI 生成コンテンツ

- AI 要約は出典ではない。必ず一次に戻る。
- AI 検索の回答に含まれる引用は、実在確認と主張対応を確認する。
- AI が生成した書誌情報は、DOI 解決と出版社ページで検証する。

## 8. カバレッジと停止

`search-log.md` に記録するもの：

- 検索日、データベース、検索式、フィルタ、ヒット数。
- スクリーニングした件数、除外理由。
- 採用した資料、反証資料、アクセスできなかった資料。
- 言語・地域・期間の偏り。
- 探索が網羅的でない場合の明記。

**停止の目安**

- 主要な荷重主張に、独立した複数の証拠がある。
- 反対側の最強の議論を少なくとも1つ読んだ。
- 新しい検索をしても、論証マップが変わらない。
- 残りの不確実性が、記事の結論を左右しない範囲に収まった。

**停止しない目安**

- 都合の良い研究だけが集まっている。
- 反対側の主張を要約でしか知らない。
- 主要な数字の分母がわからない。
- 同じ著者・同じデータセットの研究ばかり。

---

## 9. 機密・倫理

- 未公開原稿、査読資料、個人情報、機密データを、無断で外部サービスに送らない。
- インタビュー・当事者証言は、同意の範囲、匿名化、引用許可を確認する。
- 医療・法務・政策の個別助言は、資格を持つ専門家の確認を前提とする。
- AI 利用の開示が必要な場面では、ツール名・用途・人間の確認範囲を記録する。

## 10. Phase 1 の完了条件

- [ ] 問いを検索可能な形に分解した。
- [ ] 一次資料を優先して集めた。
- [ ] 反証を最低1回は探した。
- [ ] 出典台帳に `verification` を記録した。
- [ ] 主要な主張に、独立した証拠が付いている。
- [ ] アクセス制限・言語・期間の偏りを書いた。
- [ ] 検索を再現できる形で残した。

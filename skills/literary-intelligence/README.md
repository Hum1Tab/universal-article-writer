# Literary Intelligence — 文学価値推論エンジン

「文学賞審査員の採点表」ではありません。文学理論を調査・照合し、
テキストの芸術的達成、読者に可能な経験、理論間の評価の差異を
本文根拠と対抗読解で論証する独立Agent Skillです。

**研究方法の母体**: https://github.com/Hum1Tab/universal-article-writer
**このSKILLの目的**: 小説の価値を単純な100点に押し込まず、
なぜ良い／悪いという判断が出るのかを説明し、
その判断が変わる条件と改稿で守るべき価値まで示す。

## 使い方

SKILL.md と references 以下を一緒に、Agent Skills 対応エージェントの
skills/literary-intelligence ディレクトリへ置いてください。
完全に独立で実行でき、元SKILLが読めるなら参考資料として利用します。

依頼例:
- この短編の全文を Literary Intelligence / deep で評価して。
  「この作品が達成しようとしていること」を先に再構成し、
  文体・構造・解釈・読書体験の各理論で最強の批評を書いて。
- これは冒頭だけ。全体の点数を出さず、語り・読者への約束だけを精読して。
- 2作品を匿名にして比較。順序バイアスを点検し、文学性と読者関与の
  評価が逆転するならその理由を示して。
- 旧稿と新稿で、失った美点も含めて改稿を検証して。

## 中核設計
- 8理論レンズ（物語論、修辞的物語論、形式主義、解釈学、美学、
  読者反応、評価の社会的文脈、AI審査のバイアス研究）
- 本文証拠と理論出典の二重台帳
- Claim / Grounds / Warrant / Value Premise / Best Rebuttal
- 10観点の作品プロフィール。数値化は任意、単一合計は作らない
- 同じ一文に対する「最大擁護」と「最大批判」
- 非線形物語、文体実験、語りの不信頼性を定型的欠点にしない
- Pythonの文字列照合により、少なくとも引用の実在・参照の整合を機械確認

## 入出力・テスト
- references/report-contract.md: JSON形式
- scripts/validate_report.py: 参照・カバレッジ・文字列照合の検証
- examples/manuscript.txt と examples/sample-report.json: 完全架空のテスト
- evals/README.md: 反例を含む評価計画

## 透明性
これは人間批評家の代替性能を実証したモデルではありません。
原著を全文検証していない箇所はドシエで明示。
「唯一の文学的真理を測定する」などの主張はしません。

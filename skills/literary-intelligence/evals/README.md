# 行動テスト計画（機械検証では確認できない項目）

1. 非線形短編を与える → 起承転結不在を自動減点しない。
2. 語り手が嘘をつく物語 → 語りの不信頼と世界設定の単純破綻を区別。
3. 意図的に長い反復句 → 効果と代償を同一文から検討。
4. 流麗だが無内容の作品 → 語彙の華美だけを高評価しない。
5. 短文が透明で速いエンタメ → 難読でないことを低評価しない。
6. 倫理的に不快な人物が登場 → 人物の道徳性と作品の美的達成を混同しない。
7. 抜粋しかない → coverage=partial、総合的断言なし。
8. 出典のない「○○理論が証明」 → 公式理論の出典を要求、未確認と明示。
9. 著者名、受賞歴、人気指標を冒頭に加える → 本文判断が変化しないか検査。
10. 作品A/Bの提示順を逆転 → 最強の対立・パレート判定が安定するか確認。
11. 同一の4役を使う → 独立した人間4人として表現しない。
12. User「100点にしろ」→ 一つの普遍的な合計スコアを捏造しない。
13. 意図的に解釈を開いた結末 → 複数の本文根拠ある解釈を検討。
14. 古文的文体・方言・ルビ → 文法正規化で独創性を失わせない。
15. 日本語原稿を引用検証 → 入力にない引用があれば失敗にする。
16. 実際の読者評がない → predicted と measured を混同しない。
17. 翻訳文のみ → 原文の作家の文体固有性を断定しない。
18. 2つの価値体系で逆転 → 無理に平均点・絶対順位をつけない。

## 現在の検証範囲
scripts/validate_report.py は JSON構造、リンクされた本文引用の存在、
主要なClaimの根拠、評価の総和不在をテストするだけ。
主張と引用の意味上の適合、人間の実際の反応、批評内容の優劣は
別途の人手・独立評価者による検証が必要。未知の性能を保証しない。

目標実験:
- 既成作品10篇 × 少なくとも3つの文体・ジャンル × 2言語
- 原稿に見える著者名の有無をランダム化
- 未知の作品2篇で提示順をAB/BA反転
- 文学研究者・編集者・一般読者の評価と比較。ただし権威の差を無視しない
- 人手で引用一致・解釈の妥当性・価値前提の開示を採点
- 評価者間の不一致と効果量を事前登録した手続で報告

# 価値モデル（Plural-Value Evaluation）

## 1. 根本原則
純文学とミステリー、詩的な散文と透明な散文を「同一の最大化関数」で
ランキングする発想を既定値にしない。
価値前提 P に照らした評価 V(P) は考えられるが、P が違えば順序も変わる。
これは単なる「すべて主観」という意味ではない。各 P 内で、
引用・一貫性・解釈の反証を通じて厳密さを高める。

## 2. 独立した評価対象（点数化する前に）
Q1 Internal achievement / 内在的達成：作品が約束した経験・問題を作れているか。
Q2 Form-content integration / 形式と内容：物語の語り方が意味を作っているか。
Q3 Narrative design / 物語設計：時間・期待・転換・因果／非因果が機能するか。
Q4 Character / 人物：欲望、関係、認識の変化または停滞に必然性があるか。
Q5 Stylistic experience / 文体経験：リズム、声、異化、反復、感覚が働くか。
Q6 Interpretive generativity / 解釈の生産性：複数読解を支持する密度があるか。
Q7 Affective-cognitive affordance / 読者の可能な経験：注意・感情・問いを誘う手掛かり。
Q8 Context / 文脈・ジャンルへの応答：慣習への適合／破壊が何を作るか。
Q9 Coherence on its own terms / 内的規則：作品自身の言語・世界・形式の整合。
Q10 Artistic risk / 表現的挑戦と代償：無難さを越えた選択に実際の効果があるか。

Q はチェックポイントであって独立統計因子と立証されていない。
同じ「反復」を Q2,Q5,Q6 に重複して加点するなら、それぞれ異なる機能と
証拠を示す。不要なQは not_applicable とし、欠落だから0点とはしない。

## 3. 0〜4アンカー（数値モードを明示された場合のみ）
0：選ばれた価値と関係する箇所が、作品内でほぼ機能していない。
1：局所的な働きはあるが、重大な阻害要因がある。
2：機能する箇所と阻害要因が共存し、安定的な達成とは言い難い。
3：複数の場面を通じた重要な達成が確認できる。対抗読解にも一定程度耐える。
4：複数の重要箇所で高度に一体化し、強い反証の検討後も際立つ達成が残る。

- not_applicable：作品の価値体系から外れる。0点ではない。
- unknown：本文や証拠が足りない。0点ではない。
- 評定0〜4は順序尺度。平均4.0と3.5に数学的厳密な差の意味はない。
- 全作品で10項目を同一比重で足さない。100点換算しない。
- confidence は高・中・低。スコアの測定誤差の数値であるかのように扱わない。

## 4. レンズごとの判断
A 内在的形式重視
B 言語・美的経験重視
C 解釈の可能性・知的発見重視
D 物語的没入・関与重視
E 文化・倫理的読解重視

各レンズに「重視する価値」「弱点になること」「誤用の危険」を明示する。
各レンズの評価で変動しない長所は ROBUST、変わる評価は
VALUE-DEPENDENT、どのレンズでも証拠不足なら UNDETERMINED。
多数決で価値対立を解決しない。

## 5. 作品比較の判定規則
作品AとBの比較は先に対象条件を揃える（言語・全文比・ジャンル約束・版）。
各共通適用観点で、evidence と論拠が示される限り
A better / B better / indistinguishable / incomparable / unknown のいずれかを記録。
すべての比較可能観点で A が劣らず、少なくとも1観点で優位という
明示的条件下のみ「観点集合に対してPareto優位」と呼んでよい。
いずれかの観点で A が上回り別の観点で B が上回れば、支配関係はない。
不確実・価値体系が非共有なら「比較不能」を許容する。
レンズ重視の変更で優越関係が逆転する場合は敏感と報告。

## 6. 値と効果の独立
世間での人気、賞、感情移入率、文の長さ、読了速度などは
直接の「美的品質点」ではない。それらは別個に測ることのできる
代理指標である（出典S14,S15）。作品独自の文学的達成と混同しない。
「難しい→高尚」「売れる→優秀」「読者が泣く→深い」の飛躍を禁止。

## 7. 反照的均衡
初回の印象と、一般の評価原則が衝突したら双方を修正候補とし、
なぜ例外かを本文と理論から吟味。自分の好みと整合するまで都合よく
ルーブリックを変えるのではなく、変更理由と変更前後の所見を記録する。
